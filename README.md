# 心理自助 Skillpack

把几本心理学自助书拆成卡片，让 AI 在给建议之前先问对问题、该停的时候停。

起因很具体。通用 AI 碰到心理问题，毛病往往不在说得少，而在说得太顺——用户讲一句「我睡不着」，五条睡眠建议立刻摆上来；换个说法再问，又会拿到另一套。两边听着都有理，一起用就互相抵消。

所以这里的做法是反过来的：先分型，再给一张卡，且只给一张。

失眠分册里，卡 1（越想睡越清醒）让人在床上看书直到睁不开眼，卡 2（一进卧室就清醒）要求床只用来睡、睡不着就起来。方向相反，入口先用三个问题分开。焦虑分册更麻烦些——想练分级暴露的人，得先过「什么时候必须停」那张卡。顺序反了，台阶排得挺整齐，什么时候停反而没人学。

这些卡片不是书摘，写法是重新组织的。

## 里面有什么

8 个分册，70 张卡。另有 8 个还没动：DBT、囤积、神经多样性、愤怒、成瘾、哀伤、UP、LGBTQ+。

| 分册 | 卡片数 | 用户会怎么开口 |
|---|---|---|
| 自我关怀 | 12 | 「我对自己太苛刻」「一停下来就内疚」 |
| 正念·抑郁 | 10 | 「脑子停不下来」「快乐不起来」 |
| 正念减压 | 9 | 「压力大、身体紧、睡不着」 |
| 情绪调节·抑郁 | 8 | 「一件事压得慌」「我不行」「该停药吗」 |
| 失眠 | 8 | 「越用力越清醒」「一上床就醒」「想少躺一点」 |
| ACT | 9 + 2 道闸门 | 「越挣扎越深」「知道该做什么但动不了」 |
| 焦虑·惊恐 | 7 + 3 道前置 | 「分不清是真危险还是想多了」「开会不敢说话」 |

## 结构

给 AI 读的，人不必从头看到尾。

```
SKILL.md                          ← 包级入口：先读这个
references/_shell/                ← 合规外壳：危机硬停、免责、禁止清单
references/分册/失眠/00-入口.md    ← 分册入口：分型 + 路由
references/分册/失眠/cards/*.md    ← 卡片：R/I/A1/A2/E/B 六段
```

一张卡固定六段：

| 段 | 内容 |
|---|---|
| R 原文依据 | 出自哪本书哪一章。零原文引用，只记结构 |
| I 核心洞见 | 为什么这么做 |
| A1 书中案例 | 方法动作，不写情节 |
| A2 触发条件 | 用户会怎么说 |
| E 执行步骤 | 带判停点 |
| B 边界 | 什么时候不该用、书中警告过的失败模式、护栏 |

## 几条自己踩出来的线

分型要是缺了，建议给得越准越糟——它会看起来是对的。

入口筛查命中就转介。这里有个具体做法：不拿「建议寻求专业帮助」当万能结尾。每张卡都这么收，用户两周内就学会跳过它，真正该看的那次提示也一起失效。

方法从书里来，边界、中止条件、筛查问句多半是后加的。加的一律标「项目补充」，不混进书的说法里。这几条各有一个反例，收在 `docs/对抗用例库.md`。

## 什么时候别用

- 有自伤、自杀念头 —— 危机干预，不是自助
- 关系里有暴力、控制 —— 不教沟通技巧，关系亲密分册入口有专门的安全筛查
- 严重成瘾、急性精神病性症状 —— 专业治疗
- 未成年人 —— 需监护人参与

「AI 不能替代咨询师」这句话，这个包的处理是：能做的部分做扎实，做不了的明确交出去。
