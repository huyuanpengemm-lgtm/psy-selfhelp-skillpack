# 心理自助 Skillpack

把几本心理学自助书，拆成**能被 AI 判断边界**的卡片。

不是书摘，不是读书笔记，也不是「AI 心理咨询师」。
它是一套**指令结构**——用来让 AI 在给建议之前先问对问题、在该停的时候停。

---

## 它解决什么问题

通用 AI 谈心理问题时，通常有两个毛病：

| 毛病 | 表现 |
|---|---|
| **给得太快** | 用户说「我睡不着」，立刻给五条睡眠建议 |
| **给得太全** | 把互相矛盾的两套方案同时给出去，用户无所适从 |

这个包的做法相反：**先分型，再给一张卡，且只给一张。**

举两个真实设计：

- **失眠**：卡 1（越想睡越清醒）要你「床上看书直到睁不开眼」，
  卡 2（一进卧室就清醒）要你「床只用来睡，睡不着就起来」。
  **两者方向相反，同时给会互相抵消。** 所以入口先做三问分型。
- **焦虑**：想练「分级暴露」的人，必须先过「什么时候必须停」那张卡。
  **顺序反了，用户会先排台阶、后学什么时候停。**

## 怎么用

这是给 **AI 助手**读的，不是给人从头读到尾的。

```
SKILL.md                          ← 包级入口：先读这个
references/_shell/                ← 合规外壳：危机硬停、免责、禁止清单
references/分册/失眠/00-入口.md    ← 分册入口：分型 + 路由
references/分册/失眠/cards/*.md    ← 卡片：R/I/A1/A2/E/B 六段
```

每张卡是同一套六段结构：

| 段 | 内容 |
|---|---|
| **R** 原文依据 | 出自哪本书哪一章（**零原文引用**，只记结构）|
| **I** 核心洞见 | 为什么这么做 |
| **A1** 书中案例 | 方法动作，不写情节 |
| **A2** 触发条件 | 用户会怎么说 |
| **E** 执行步骤 | 带判停点 |
| **B** 边界 | 什么时候**不该**用、书中警告过的失败模式、护栏 |

## 三条设计原则

### 一、先分型，再给卡

分错型的建议，比不给建议更糟——因为它看起来是对的。

### 二、该停的时候停

每个分册都有入口级筛查。命中即转介，且**不写「建议寻求专业帮助」当万能结尾**——
每张卡都这么写，用户两周内就学会无视它，**会让真正的危机提示失效**。

### 三、标注哪些是我们补的

方法来自书，但**边界、中止条件、筛查问句**很多是我们加的。
凡是补的，一律标 `项目补充`，不伪装成书里的。

三条原则各有一个反例，写在 `docs/对抗用例库.md`。

---

## 边界

**不适用的情况**（这些不是「效果差一点」，是「不该用」）：

- 有自伤、自杀念头 → 危机干预，不是自助
- 关系里有暴力、控制 → 不教沟通技巧
- 严重成瘾、急性精神病性症状 → 专业治疗
- 未成年人 → 需监护人参与

**关于「AI 不能替代咨询师」这句话**：本包的态度不是「所以别用」，
而是**把 AI 能做的部分做扎实，把不能做的部分明确交出去**。
