# 心理自助 Skillpack

## 一、问题

通用对话系统处理心理主诉时存在两类偏差。

其一为响应过早。用户在陈述单一症状（如「我睡不着」）后，即获得成组的干预建议，而分型所需的信息尚未采集。

其二为响应过宽。适应证相互冲突的方案被并列输出，各方案在自身条件下均成立，合并使用时效果相互抵消。

两类偏差单独出现时未必造成明显错误，但均源于同一机制：系统缺少在给出建议之前进行分型与边界判断的结构。

## 二、方法

本工具包将若干已出版的心理学自助书籍中的干预程序，抽取为结构化卡片，并在其前置一层分型入口。设计目标不在扩充可提供的建议数量，而在约束建议的范围、顺序与时机。

原则为：先分型，后给卡，一次仅输出一张。

以失眠分册为例。卡 1 适用于「越想睡越清醒」，要求患者在卧床时阅读直至困意难以支撑；卡 2 适用于「一进卧室即清醒」，要求床仅用于睡眠，卧床后无法入睡则离床。两者方向相反，同时给出将相互抵消，故入口先以三个问题完成分型。

焦虑分册的情况略有不同。分级暴露的开展以中止条件为前提，若顺序颠倒，使用者往往完成阶梯的编排，而未习得中止的判据。

上述卡片均经重新组织表述，不构成原书的摘录。

## 四、结构

本工具包面向语言模型读取，不要求人工通读。

```
SKILL.md                          ← 包级入口：先读此项
references/_shell/                ← 合规外壳：危机硬停、免责、禁止清单
references/分册/失眠/00-入口.md    ← 分册入口：分型与路由
references/分册/失眠/cards/*.md    ← 卡片：六段结构
```

单张卡片采用固定六段：

| 段 | 内容 |
|---|---|
| R 原文依据 | 所据书目与章节；零原文引用，仅记录结构 |
| I 核心洞见 | 该程序的机制说明 |
| A1 书中案例 | 演示的方法动作，不含情节 |
| A2 触发条件 | 对应的主诉表述 |
| E 执行步骤 | 含判停条件 |
| B 边界 | 不适用情形、原书所述失效模式、护栏 |

## 五、设计约束

分型缺失时，建议的准确度与危害性同向增长：越是贴合主诉的建议，越容易被误认为适用于该使用者。

入口筛查命中的情形，本工具包不作方法转授。此处采用一项具体处理：不以「建议寻求专业帮助」作为每张卡片的固定结尾。该表述在重复出现后将被使用者忽略，进而使真正需要被识别的那一次提示同时失效。

卡片所述方法来自原书，而边界条件、中止条件与筛查问句多为后加。后加内容一律标注为「项目补充」，不与原书表述混同。三类约束各附一则反例，收录于 `docs/对抗用例库.md`。

## 六、适用范围

下列情形不属适用范围。此处的限定并非指效果减弱，而是指不该使用。

- 存在自伤或自杀意念：属危机干预范畴，不属自助范畴
- 关系中存在暴力或控制：不转授沟通技巧，关系亲密分册入口另设安全筛查
- 严重成瘾或急性精神病性症状：属专业治疗范畴
- 未成年人：需监护人参与

关于「AI 不能替代咨询师」这一判断，本工具包的立场是：将可承担的部分做完整，将不可承担的部分明确移交，而非据此否定工具本身的使用。
