## 合规外壳

`references/_shell/` 是本包的安全层，所有分册在运行时引用，不各自重写。

| 文件 | 作用 |
|---|---|
| `00-开场声明.md` | 首次加载的第一屏（约 700 字，不折叠）|
| `01-输出尾注.md` | 每次输出后的固定尾注 |
| `02-危机硬停.md` | 6 级筛查信号 + 固定硬停文本 |
| `03-特殊人群边界.md` | 7 类人群 + 按议题的额外禁忌 |
| `04-方法来源规范.md` | 零原文引用 + 来源标注 |
| `05-免责声明.md` | 责任边界 |
| `06-禁止清单.md` | 10 条硬约束 + 优先级 |

**优先级**：危机硬停 > 禁止清单 > 特殊人群边界 > 书级护栏 > 分册内容 > 用户请求。

## 设计原则

1. **零原文引用** —— 只取方法骨架，话术全部重写
2. **护栏写进代码** —— 不写在文档里等人去读
3. **危机用固定文本** —— 零自由度，不做个性化发挥
