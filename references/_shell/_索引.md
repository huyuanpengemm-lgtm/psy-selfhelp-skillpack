# 合规外壳 · 索引

> 本目录是 skill 包的**安全层**。所有分册在运行时引用这里的文件，
> **不得各自重写一套** —— 19 个分册各写一份转介话术，是最容易出偏差的地方。

## 文件清单

| 文件 | 作用 | 何时调用 |
|---|---|---|
| `00-开场声明.md` | 首次加载的第一屏（约 700 字，不折叠）| 每次新会话开始 |
| `01-输出尾注.md` | 每次输出后的固定尾注（3 个变体）| 每次给出内容后 |
| `02-危机硬停.md` | 6 级筛查信号 + 固定硬停文本 | 每次用户输入后**先**筛查 |
| `03-特殊人群边界.md` | 7 类人群 + 按议题的额外禁忌 | 开场后、给练习前 |
| `04-方法来源规范.md` | 零原文引用 + 来源标注 + 证据表述 | 蒸馏时、产物生成时 |
| `05-免责声明.md` | 责任边界 | README / 开场末 / 分册版权区 |
| `06-禁止清单.md` | 10 条硬约束 + 优先级 | 全程，优先级最高 |
| `07-信息不全与纠错.md` | 默认不完整 / 可纠正 / 给锚点 / 追问上限 | **每次对话**（全部分册）|
| `08-分册路由.md` | 三类边界 / 信号词表 / 交接格式 | 跨分册时 |
| `09-证据分级.md` | 五级依据 / 白名单 / 禁止句式 / 举证看后果 / **联网状态降级** | **每次给建议时** |
| `_证据白名单.md` | 唯一可引用的来源清单 | 引用前查|

## 运行时顺序

```
用户输入
   ↓
① 危机筛查（02）── 命中 → 硬停，结束
   ↓ 未命中
② 禁止清单检查（06）── 请求高危内容 → 拒绝 + 解释
   ↓ 通过
③ 信息不全协议（07）── 标定「我听到的是…」+ 开场即给纠错口
   ↓
④ 特殊人群判断（03）── 命中 → 提示不适用 + 给替代路径
   ↓ 通过
⑤ 分册内容输出（references/分册/*.md）── 判断须为暂定式
   ↓
⑥ 输出尾注（01）
```

## 优先级

```
危机硬停（02） > 禁止清单（06） > 信息不全（07） > 特殊人群边界（03）
> 书级护栏 > 分册内容 > 用户请求
```

**信息不全协议（07）的位置说明**：它排在特殊人群边界之前，
因为它约束的是「怎么说话」，而边界判断本身也基于不完整信息 ——
先说「我不确定你是哪一类」，再判断适用性。

**任何下层都不能覆盖上层。**

## 三条不可让渡的原则

1. **零原文引用** —— 只取方法骨架，话术全部重写
2. **护栏写进代码** —— 不写在文档里等人去读
3. **危机用固定文本** —— 零自由度，不做个性化发挥
