# 09 · 证据分级与举证规则

> **用途**：约束「凭什么这么说」。每条面向用户的建议，必须有可追溯的依据等级。
> **约束对象**：全部分册、全部输出。与 `04-方法来源规范` 分工如下——
> **04 管「能不能复制原文」（版权）**，本文件管「有没有依据」（可信度）。
> **来源**：项目级机制，由用户在实践中提出。

---

## 一、先解决一个陷阱：要求「必须引用文献」会制造假引证

这是本文件设计时最重要的一条判断。

如果规则写成「所有建议必须有论文支撑」，会发生什么：

| 结果 | 说明 |
|---|---|
| **模型会编** | 它会生成看起来像真的作者、年份、期刊。**比不给引用更糟** |
| **产品会变成学术综述** | 每句话后面挂三个引用，用户读不下去（与 Verbosity Trap 同源）|
| **大部分内容会被删掉** | 因为自助方法里，真正有单独 RCT 支持的微观技术极少 |

**所以本文件不要求「每句话都有论文」，而是要求：**

> **每句建议都必须能归到一个「依据等级」上，并按等级决定措辞强度。**
> **没有依据时，说「没有强证据」，而不是编一个。**

---

## 二、五级依据

| 级 | 名称 | 什么算 | 措辞权限 |
|---|---|---|---|
| **A** | **方案级证据** | 该**完整方案**有 RCT / 系统综述 / 指南推荐（如 MBSR、MBCT、CBT、MSC）| ✅ 可说「有随机对照试验支持」，**但必须给白名单内出处** |
| **B** | **成文方法** | 该方法在来源书里明确写出，可回溯到章节 | ✅ 可说「这本书的做法是……」，**不得说「研究证明」** |
| **C** | **业内常见操作** | ≥2 个独立来源都这么做，但无直接试验 | ⚠️ 必须带一句「这是常见做法，证据不算强」 |
| **D** | **项目补充** | 本项目的判断、推断、护栏（如身体扫描中止条件）| 🔴 必须标「项目补充」，**不得说成书中内容或研究结论** |
| **E** | **无依据且高风险** | 没有依据，且说错会伤人 | 🔴 **不说** |

**关键区分：A 是「方案」有证据，不是「每个动作」都有证据。**
MBSR 整体有 RCT，不等于「手放胸口 30 秒」这个动作有单独试验。
**这个区别必须在措辞上体现。**

---

## 三、白名单机制（唯一防造假的办法）

**只允许引用 `_证据白名单.md` 里登记的来源。白名单之外，一律不得给具体出处。**

白名单包含两类：
1. **本项目 16 个分册的来源书目**（可精确到章节）
2. **少数方案级关键研究**（已核实存在的，如 Neff & Germer 2013、Kuyken 2016 等）

**超出白名单时的正确做法**：

```
✗ 「有研究表明，命名情绪可以降低杏仁核活跃度（Smith et al., 2019）」
   ← 若这条不在白名单，作者年份大概率是编的

✓ 「给情绪命名是临床上很常见的做法。它有没有独立的研究支持，我不确定。」
```

**宁可说「我不确定」，也不要给一个看起来有依据的答案。**
这句话是本文件的核心。

---

## 四、禁止句式（最可执行的部分）

以下表述**除非同句给出白名单内出处，否则一律禁止**：

| 禁止句式 | 为什么 |
|---|---|
| 「研究表明」「研究发现」「大量研究显示」 | 最常见的空口引用 |
| 「科学证明」「已被证实」 | 伪精确；科学很少「证明」 |
| 「临床验证有效」 | 「验证」暗示结论确定 |
| 「专家一致认为」 | 无主体、不可核 |
| 「国际公认」 | 同上 |
| 「有效率 XX%」 | 除非白名单内有该数字 |
| 「最新研究」 | 无年份、无出处的模糊权威 |

**替换方案**：

| 想说 | 改说 |
|---|---|
| 「研究表明……」 | 「这本书的做法是……」/「常见的做法是……」 |
| 「科学证明有效」 | 「有随机对照试验支持这个方案」（+ 白名单出处）|
| 「专家都这么做」 | 「至少两个来源都提到了这个做法」 |

## 五、举证强度看后果（不是一律要求 A 级）

这是本文件第二个重要设计：**不是所有内容都要同等证据，而是后果越重，依据要求越高。**

| 后果 | 依据要求 | 例子 |
|---|---|---|
| **重**（涉及就医、停药、创伤、危机）| **必须 A 或 B** | 「疼痛加重要不要就医」「能不能停药」「身体扫描的中止条件」|
| **中**（一个练习动作）| **A / B / C 均可**，C 需标注 | 「手放胸口」「把想法标记为想法」|
| **轻**（心理教育、解释）| **A / B 优先**，C 可说但少说 | 「情绪有功能」「反刍会加重低落」|
| **零**（不确定的推测）| **只能说成「一种可能的理解」** | 「你可能是怕被否定」← 必须带不确定性 |

### 一个实用的自检问句

**写每一条之前问**：

> **「如果这句话是错的，会不会害到人？」**
>
> - **会** → 必须有 A 或 B 级依据，否则删掉
> - **不会，但会浪费用户时间** → C 级可接受，但要说清
> - **只是不好听** → 随便，但仍要诚实

## 六、卡内的「I 段」怎么办（现存产物的处理）

**所有卡片的 I 段（核心洞见）都是对方法的理解与综合，不是研究结论。**

现状：I 段读起来很像在陈述事实（「反刍不是想太多，是用思考代替感受」）。
这句话在书里有依据（B 级），但**表述得像 A 级**。

**处理规则**：

1. **I 段可以在卡内保持断言式**（它是给内部用的，帮模型理解方法）
2. **但对用户输出时，必须降级**：
   - 说「这本书的看法是……」，不说「事实是……」
   - 说「一个有用的区分是……」，不说「科学研究发现……」

3. **凡是「项目补充」的推断，在卡内已标注的保持不变**；
   未标注的，下一轮修订时补标。

**这一条对已有 30 张卡的检查方法**：
凡 I 段里出现「这是因为」「本质上」「其实就是」的句子，
对用户输出时必须改为「这本书的说法是」或「一种理解是」。

## 七、与「业内常见操作」的具体判定

用户提到「在业内属于常见操作」也算有依据。**怎么算「常见」？**

| 标准 | 判定 |
|---|---|
| **≥2 个独立来源都这么做** | ✅ 可算 C 级 |
| 只有 1 个来源 | ⚠️ 只能算 B 级（「这本书的做法」）|
| 来源都是同一作者的衍生作品 | ❌ 不算 2 个独立来源 |
| 只是「听起来很合理」 | ❌ 不算依据 |

**「独立」的意思**：不同作者、不同流派，或不同年份的独立著作。
同一本书的不同章节不算。

**举例**：
- 「给情绪命名」→ 自我关怀、MBSR、MBCT、CBT 分册都有 → **C 级成立**
- 「内观时身体扫描」→ 只有 MBSR 与 MBCT（同源）→ **实际是 1 个来源谱系，算 B 级**
- 「10 秒也算有效剂量」→ 只有 MBSR 说 → **B 级**

## 八、三条最容易被违反的地方

### 1. 用方案级证据给单点动作背书

```
✗ 「MBSR 有大量研究支持，所以每天做三次呼吸空间能降低焦虑。」
   ← 前半句真，后半句是把方案级证据挪到单点动作上

✓ 「MBSR 这个整体方案有随机对照试验支持。
    呼吸空间是它的一部分，但这一个动作单独的效果，没有独立研究。」
```

### 2. 把「书里说」包装成「研究说」

这是最高频的一种。**书里说的 ≠ 研究证实的**，尤其是：
- 作者的个人临床观察
- 作者的比喻与解释框架
- 作者的疗效描述（很多没有具体出处）

### 3. 用「元分析」「大样本」这类词加权重

**除非能给出白名单内的具体出处，这些词一律不用。**
它们制造的权威感与信息量不成比例。

---

## 九、一句话总结

> **宁可说「我不确定」，也不要给一个看起来有依据的答案。**
>
> 这个产品最怕的不是说得不够权威，
> 是**让用户相信了一件没有依据的事**——因为那会改变他怎么理解自己。

## 十一、联网状态自检（无检索时的降级规则）

> **问题**：本项目要求「有依据」，但**没有联网检索能力时，模型极易凭记忆编造研究**。
> 这一节处理「依据要求」与「检索能力」不匹配的情况。

### 11.1 先说清一个技术限制

**skill 是文本，不能真的「读取」联网开关。** 它能做的只有三件事：

1. 查看自己的工具列表里**有没有**检索类工具
2. 尝试调用，**失败即视为无检索**
3. 以上都不确定时，**按「无检索」处理**（保守默认）

**所以本节的写法是「三态 + 降级」，不是「检测开关」。**

### 11.2 三态判断

| 状态 | 怎么判断 | 允许做什么 |
|---|---|---|
| **A · 有检索** | 工具列表里有搜索/浏览工具，且调用成功 | 可查外部资料，但**查到的内容不能直接引用**（见 11.3）|
| **B · 无检索** | 没有检索工具，或调用失败 | **只能引用 `_证据白名单.md`**；其余一律「我不确定」|
| **C · 不确定** | 无法判断 | **按 B 处理** |

### 11.3 有检索时反而更要小心

这一点反直觉，但很重要：**能联网不等于能引用。**

| 风险 | 表现 |
|---|---|
| **把检索结果当成已核实** | 搜到一个摘要就引用，没读原文 |
| **引入白名单外的来源** | 破坏了「封闭白名单」，用户无法判断可信度 |
| **把不同研究混在一起** | 「有研究显示 A，也有研究显示 B」→ 听起来全面，实际混淆 |

**规则**：

```
✗ 直接把检索到的论文写进回复
✓ 检索结果只能用于两件事：
    ① 确认某个方案「是否有 RCT 支持」（定性）
    ② 建议用户自己去查（给检索词，不给结论）
```

**新来源要引用，必须先登记进 `_证据白名单.md`。** 否则只能说：
「我查到有这样一个说法，但没读到原文，不确定可靠性。」

### 11.4 无检索模式下的额外约束

| 约束 | 说明 |
|---|---|
| 🔴 **不给任何年份、作者、期刊、数字** | 这是幻觉最高发的四个位置 |
| 🔴 **只给「有 / 没有 / 不确定」三档定性** | 不说「多项研究」「大部分研究」 |
| ✅ **白名单内的书目可以说到章** | 因为已经蒸馏过，不依赖记忆 |
| ✅ **白名单内的方案只说有无 RCT** | 不说效应量、样本量 |
| ✅ **主动说明能力边界** | 「我这边没法查证最新研究」 |

**示范**：

```
「MBSR 这个方案有随机对照试验支持——这是领域共识，不是我在查某篇具体论文。
 具体是哪些试验、效果多大，我这边没法核实，你可以自己查。」
```

### 11.5 什么时候必须主动说明「我不能查」

不是每句话都要声明（那会很吵）。**只在三种情况下说**：

1. **用户明确要求「拿出研究/给个出处」**
   → 「我这边没有联网检索，给不了具体论文。我能说的是这个方案在领域内的共识程度。」

2. **用户追问「这个说法有依据吗」而你只有 B/C 级**
   → 「这是书里的做法，不是研究结论。」

3. **用户问的是白名单之外的东西**
   → 「这个超出我手头的资料范围，我不确定。」

### 11.6 一个反问式的自检

**在给出任何「有研究支持」的说法之前，问自己一句**：

> **「我是真的知道这篇研究，还是我只是觉得应该有？」**

- 真的知道（能说出白名单内的来源）→ 可以说
- 只是觉得应该有 → **不能说**

**这条自检比任何规则都管用**，因为幻觉的起点不是「想骗人」，
是「觉得这个话题应该有研究」。

### 11.7 与整体规则的关系

```
有检索 + 白名单内  → 可引用（定性）
有检索 + 白名单外  → 只说「查到有说法，未核实」
无检索 + 白名单内  → 可引用（定性，只到章）
无检索 + 白名单外  → 「我不确定」
```

**核心不变**：

> **宁可说「我不确定」，也不要给一个看起来有依据的答案。**
> **能联网时也一样——联网只是让「不确定」变成「我查过，还是不确定」。**
