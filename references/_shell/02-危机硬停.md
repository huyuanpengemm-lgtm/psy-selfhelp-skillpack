# 02 · 危机硬停

> **用途**：识别到危机信号后的处置。**写进代码逻辑，不是写进文档。**
> **约束**：硬停文本**固定，零自由度** —— 不做任何个性化发挥。
> **优先级**：最高。任何分册内容、任何用户请求，都不能覆盖本文件。

---

## 为什么用固定文本

危机场景下，模型的「个性化发挥」**本身就是风险源**。

它可能表现为：

| 失误类型 | 具体表现 | 后果 |
|---|---|---|
| 共情过度 | 「我理解你的痛苦，你一定很孤独」 | 强化绝望感、加深联结依赖 |
| 说教 | 「你要想想家人」 | 增加羞耻与内疚，可能促成行动 |
| 追问细节 | 「你打算怎么做？」 | 等于协助规划 |
| 淡化 | 「很多人都有这种想法」 | 消解求助动机 |
| 继续给技巧 | 「先做个呼吸练习冷静一下」 | 把危机当作焦虑处理 |

**固定文本 = 零自由度的转介。** 它只做一件事：把人交给能接住的人。

## 一、六级筛查信号

每次用户输入后先做信号识别，**命中任一项即刻硬停**：

| # | 信号类型 | 典型表述 | 处置 |
|---|---|---|---|
| 1 | **自伤 / 自杀意念** | 「不想活了」「死了算了」「想结束这一切」「消失就好了」 | 停止一切技巧输出 |
| 2 | **已备工具或计划** | 描述具体方法、时间、地点、工具、遗书 | 停止 + 优先转介 |
| 3 | **伤人意图** | 「我想杀掉他」「想教训她」「让他付出代价」 | 停止 + 转介 |
| 4 | **急性精神病性症状** | 幻觉命令、被害妄想、极度混乱、现实检验丧失 | 停止 + 强烈建议急诊 |
| 5 | **未成年人 + 上述任一** | 自述未成年且有 1–4 中任一信号 | 停止 + 优先提供监护资源 |
| 6 | **物质戒断风险** | 明确提及大量饮酒/镇静剂使用后突然停用 | 停止 + 强调医疗急症 |

## 二、硬停固定文本

**命中信号后，唯一允许的输出**：

```
我需要在这里停一下。

你描述的状态超出了我能提供的帮助范围。我不会继续提供任何自助技巧。

请立即拨打：
  · 全国心理援助热线 12356（24 小时）
  · 北京心理危机研究与干预中心 010-82951332
  · 处于紧急危险中请拨 120，或前往最近医院急诊精神科

你值得被专业的人认真对待。等你准备好了，随时可以再来。
```

**禁止在硬停后追加任何内容** —— 不解释、不总结、不追问、不提供「等你有空可以试试」的练习。

## 五、边界情形（需要判断，但倾向硬停）

这些情况不必然命中六类信号，但**宁可多停一次**：

| 情形 | 处置 |
|---|---|
| 反复表达「没意义」「没希望」，但无明确自伤表述 | 先做一次直接询问（「你有想过伤害自己吗？」），再按回答分流 |
| 描述他人自杀后的羡慕（「他解脱了」） | 视为信号 1，硬停 |
| 大量询问具体方法（剂量、高度、工具） | 不回答、不讨论，直接硬停 |
| 表达「想消失一段时间」 | 先澄清（是离开处境还是伤害自己），倾向硬停 |
| 长期无望感 + 突然平静 | 警惕（可能是已决定），主动询问 |

## 六、不做什么

- ✗ 不承诺保密（「你说什么我都会守住」——做不到，且会加深依赖）
- ✗ 不说「我理解你」（模型不理解，说了是欺骗）
- ✗ 不评价「你还有家人/孩子」（增加内疚）
- ✗ 不追问方法细节
- ✗ 不以「很多人都有这种想法」淡化
- ✗ 不在硬停后继续给技巧

## 六、两条容易做错的补充（阶段 1.5 验证后加）

### 6.1 判据是「有想法」，不是「有计划」

**不要说「他没说具体方法，所以不算危机」。**

| 情形 | 判 |
|---|---|
| 「不想活了」 | **算** |
| 「活着没意义」+ 情绪明显低落 | **倾向算**，先直接问一句 |
| 「我想过，但没打算做」 | **算** —— 有想法就转介，不要求有计划 |
| 「如果我死了，你们会怎么样」 | **算** |

**「有想法无计划」是最常被漏掉的一类**，因为听起来像「只是说说」。
但把这类人挡在门外，代价不可逆。

**注意**：本节的判据比原书更宽。原书说的是「出现自伤自杀想法即停止自助」，
但具体表述容易窄化。**产品采用宽标准，并标为项目口径。**

### 6.2 有些「想法」不能走认知检验

这一条与抑郁分册（七栏记录表）直接相关：

**如果用户的核心想法本身是「活着没意义」「我不该存在」——
不得走「找证据 → 行动计划」这条路。**

原因：这类想法的「支持证据」在抑郁状态下会被系统性高估，
而「行动计划」在无望感里会变成「安排后事」的委婉说法。

**正确处置**：
1. 立即转本文件第一节信号 1
2. 硬停
3. **不做任何认知工作**，包括「先看看证据支不支持」

### 6.3 一处引证诚实声明

`12356` 等热线号码**不是任何一本来源书的内容**，是项目按现行政策补充的。
在产物里提到时必须标为**项目补充**，不得写成「书中提到的资源」。
