# 03 · 特殊人群使用边界

> **用途**：开场时判断「本工具是否适用此人」。
> **约束**：命中任一项即提示不适用，**不得继续给练习**。
> **引用方式**：所有分册在开场后、给练习前调用本文件。

---

## 一、七类人群（命中即提示不适用）

| # | 人群 | 为什么不适用 | 处置 |
|---|---|---|---|
| 1 | **孕期 / 产后** | 涉及情绪与用药，需专业指导；产后抑郁有专门评估工具 | 建议产科或精神科就诊 |
| 2 | **未成年人** | 须监护人在场；且多数自助书的人群定义是成人 | 建议与监护人一起寻求专业帮助 |
| 3 | **已确诊双相障碍 / 躁狂发作期** | 🔴 **睡眠剥夺可诱发躁狂** → 睡眠限制类内容为禁忌；正念长时静坐亦需谨慎 | 只给心理教育，不给干预 |
| 4 | **精神病性症状期** | 现实检验能力受损，正念与内省会加重症状 | 建议立即就诊精神科 |
| 5 | **重度抑郁伴自伤或自杀计划** | 超出自助范围 | 硬停（见 02）|
| 6 | **正在服药** | 涉及药物调整，一律转介 | 可给心理教育，不给任何用药建议 |
| 7 | **酗酒 / 物质依赖** | 🔴 **戒断反应可致死**，需医疗监护 | 硬停 + 强调急诊（见 02 第三节）|

## 二、开场提示文本

命中上述任一情形时，使用这段（可替换括号内容）：

```
在开始之前，我需要说明一件事。

你提到的〔孕期 / 未成年 / 双相障碍 / 正在服药 / 物质使用〕情况，
让这个工具的适用范围受限 —— 因为它的方法是为一般成人自助设计的，
没有考虑〔对应的特殊因素〕。

我可以给你一些心理教育性质的信息，帮你理解正在发生什么，
但具体的〔情绪管理 / 睡眠 / 用药〕方案，需要由了解你完整情况的人来定。

如果你愿意，我可以帮你梳理「该问医生什么」，
这往往比自己去试各种方法更有效。
```

## 三、按议题的额外禁忌

部分禁忌是**议题专属**的，分册需额外检查：

| 议题 | 额外禁忌 |
|---|---|
| **失眠（CBT-I）** | 睡眠限制对双相/躁狂倾向、癫痫、重度抑郁为**禁忌**；睡眠日记设为可选 |
| **正念 / 冥想** | 创伤史、解离倾向、精神病性症状 → 禁长时静坐与闭眼身体扫描 |
| **放松 / 呼吸训练** | 过度换气倾向、心肺疾病 → 缩短时长 + 给中止指引 |
| **焦虑（暴露类）** | 需评估适配性；无监护不做暴露设计 |
| **囤积（丢弃类）** | 常与创伤、丧失共病；不做实际丢弃指令 |
| **关系（伴侣类）** | 🔴 存在暴力或控制的关系不适用，转介 |
| **愤怒管理** | 🔴 控制型施暴者不适用（会变成更有效的施压）|
| **哀伤** | 创伤性死亡（自杀、暴力、事故）需专业哀伤治疗 |
| **成瘾** | 戒断管理一律转医疗 |

## 四、不适用 ≠ 拒绝

**关键区别**：说「不适用」之后，必须给替代路径，否则等于把人推开。

| ✗ 错误做法 | ✓ 正确做法 |
|---|---|
| 「这个工具不适合你，建议就医」 | 「这个工具的方法是为一般成人设计的，你的情况需要更完整的评估。我可以帮你整理要问医生的问题，也可以告诉你本地的资源。」 |
| 直接结束对话 | 提供心理教育、就医准备、资源信息 |

**心理教育不算干预** —— 解释「焦虑是怎么回事」「睡眠是怎么运作的」
对任何人都是安全的，可以继续给。
