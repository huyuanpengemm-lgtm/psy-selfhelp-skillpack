## 一、四个必须先定的译名

### 1. 正念 = mindfulness（全包已统一）

三本正念类书的工作用词：
- 本册（多舛的生命）：**正念**
- MBCT（八周正念之旅）：**正念**
- 自我关怀：原译「静观」，**已统一替换为「正念」**

**本册「静观」仅 5 次，且都在他人推荐语里**，非工作用词。

### 2. 行为模式 = 行动模式（同一个二分，两个译名）

| | 本册 | MBCT |
|---|---|---|
| 叫法 | **行为模式**（13 次）· 存在模式（7 次）| **行动模式** · 存在模式 |
| 含义 | 完全相同 | 完全相同 |

**处理**：产品统一用「**行动模式**」，本册引用时加注「本书译作行为模式」。
**不声明这一点，用户会以为是两套框架。**

### 3. 苦难 = 痛苦（suffering）

| | 本册 | MBCT |
|---|---|---|
| 译名 | **苦难**（38 次）| **痛苦** |
| 对应 | pain vs suffering | 第一支箭 / 第二支箭 |

**处理**：对外统一用「**痛苦**」，引用原文保留「苦难」并加注。
**但「疼痛 ≠ 痛苦」这个表述本身要保留** —— 它是本册最有名的区分。

### 4. 不争（书中亦作「无争」）

不争 9 次 / 无争 2 次 → **统一用「不争」**。

## 二、七个态度（本册的价值基座）

| 态度 | 英文 | 一句话 |
|---|---|---|
| **非评判** | non-judging | 评判的念头出现时，识别它，搁置评判，取一个更宽广的视角 |
| **耐心** | patience | 允许事情按自己的节奏展开，不催 |
| **初心** | beginner's mind | 愿意看待万事万物都如初见。**没有一个时刻与别的时刻相同** |
| **信任** | trust | 相信自己的感受与直觉，不因为别人说「应该」就否定它 |
| **不争** | non-striving | 除了做你自己外别无目标。**达成目标的最好方式是停止追求** |
| **接纳** | acceptance | 看见事物此刻的本来面目。**不意味着喜欢，也不意味着认命** |
| **放下** | letting go | 让事情任其自然。书里用猴子抓香蕉的寓言：要自由，只需松手 |

**关键**：七条**不是七个考核项**，是练习进行不下去时的**分诊表**。只查一条，不查七条。

## 三、核心概念

### A 组 · 心智状态

| 术语 | 英文 | 一句话 |
|---|---|---|
| **正念** | mindfulness | 「看到并知道你正在看见」。不只是概念上知道，是**直接知道** |
| **自动导航** | automatic pilot | 机械性地运作，对正在做的没有全然觉知。**很多时间我们并不真正「在家」** |
| **无为** | non-doing | 「我所知道的唯一不牵涉到要到别处去，而强调在你已经所在的地方的人类努力」 |
| **完整性** | wholeness | 你本来就是完整的。**无须变成你本来是的那个样子** |
| **相互关联** | interconnectedness | 「正念就是关系」 |

### B 组 · 压力与疼痛

| 术语 | 英文 | 一句话 |
|---|---|---|
| **压力反应** | stress reaction | **自动且无意识**发生 |
| **压力回应** | stress response | 正念介导，需要空隙；不需要先让唤起降下来 |
| **疼痛** | pain | 生命自然体验的一部分 |
| **苦难 / 痛苦** | suffering | 来自想法、情绪、以及我们如何建构体验的意义。**只是对疼痛体验的一种反应** |

### C 组 · 具体练习

| 术语 | 英文 | 一句话 |
|---|---|---|
| **身体扫描** | body scan | 躺姿，逐段移动注意力，**重建身心关系** |
| **坐姿冥想** | sitting meditation | 正式练习的核心。与平常打坐的差别在于**觉知** |
| **正念瑜伽** | mindful yoga | 第三个正式练习。**正念地做，它就是冥想** |
| **正念行走** | mindful walking | 单纯地行走，并知道你在行走。**不是看你的脚** |
| **呼吸作为锚** | breath as anchor | 观察想法时，呼吸是「大本营」 |
| **无拣择的觉知** | choiceless awareness | 与每个瞬间展开的一切同在 |

## 四、术语使用四条规则

1. **跟随用户用词**。用户说「正念」答「正念」，说「冥想」答「冥想」，不纠正。
2. **不主动引入术语**。用户说「我老绷着」，不要回「这是压力反应」——先说人话。
3. **术语不做诊断**。「这类反应有一个特点」是描述；「你有焦虑倾向」是诊断，禁止。
4. **不给「标准体验」**。书里明确：放松可能发生，也可能不发生。
