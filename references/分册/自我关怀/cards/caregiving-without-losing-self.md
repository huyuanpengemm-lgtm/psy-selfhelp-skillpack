## I · 核心洞见

> **依据等级 B（成文方法）**——本段是对方法的理解与综合，**不是研究结论**。
> 对用户输出时须降级为「这本书的看法是……」，不得直接说成事实。
> 若其中某条是本项目的推断，须标「项目补充」。


**这张卡处理两件事：给太多的人、收不了的人。**

**核心区分：共情 ≠ 关怀**

| | 共情（empathy） | 关怀（compassion） |
|---|---|---|
| 状态 | 与对方的痛共振 | 稳定地托住对方 |
| 身体感受 | 胸口紧、跟着难受 | 温暖、有力 |
| 持续久了 | **耗竭**（共情疲劳） | 可持续 |
| 隐含信息 | 「我也很痛」 | 「我在这儿，你不孤单」 |

照料者之所以耗竭，往往不是「付出太多」，是**停在共情里太久**。
一直跟对方一起痛，痛到最后自己也需要被救。

**转向的具体做法**：不是「少关心一点」，是**换一种状态**——
从「我与你感同身受」换成「我抱持着你」。
在呼吸上做：**吸气时给自己一点关怀，呼气时把关怀给对方。**
这个动作很小，但它改变的是「谁在承接谁」。

**第二个问题：只给不收**
有些人能对所有人好，唯独接受别人的关心时会不适、想推掉、觉得欠人情。
书里的观察是：单向付出会走向耗竭，然后生出隐秘的怨恨
（「我为你们做了这么多，没人管我」），而这份怨恨又会引发羞耻。
**接受本身就是自我关怀的一部分**，不是自私。

## A1 · 书中案例

**案例一：抢着给建议的朋友**
一位学员在朋友倾诉时不断打断、抢着出主意。
书里的解读是：她受不了朋友的痛苦，所以急着「解决」它，好让自己不必待在那份痛苦里。
**方法要点**：抢着帮忙，常常是在回避自己的共情之痛。
转向是先承认自己的不适，再回来听。

**案例二：公共场所里照料对象突然失控**
一位照料者在公共场合面对被照料者的突发状况，感到羞耻、愤怒、无助交织。
书里的路径是先给自己一句「这真的很难」，再回到处置。
**方法要点**：不先安顿自己就处置，会把羞耻转嫁到被照料者身上。**

## A2 · 触发条件

**用户会在这些情境下需要它：**

1. 说「我一直在帮别人，但没人帮我」
2. 照顾家人/病人/孩子到精疲力竭
3. 一停下来就内疚
4. 别人关心自己时想推掉、觉得不自在
5. 做助人工作（咨询、护理、教育）且感到耗竭

**语言信号**（中／英）：
- 「我一直在照顾别人」「没人管我」「一休息就内疚」
- 「我不习惯被人照顾」「欠人情」
- "I'm burnt out from caring for others" / "I can't accept help" / "I feel guilty resting"

**与相邻卡的分工**（初稿）：
- 与**卡 10** 的区别：卡 10 是「我需要什么」（向内诊断），

## E · 执行步骤

**第零步：先看有没有现实约束**（重要的分流）

如果用户的话里包含**具体现实冲突**——辞职、钱、谁来做、搬到哪——
那么这**不是认知问题，是处境问题**。

例：「我妈说我自私，因为我不肯辞职照顾她」
→ 不要先去改「自私」这个认知（卡 2），也不要先剥愤怒（卡 9）。
→ **先谈处境**：现在实际谁在照顾？辞职的代价是什么？有没有第三个人？

**规则：有现实约束时，先谈资源与边界，再谈认知。**
倒过来会变成「你想法不对」，而用户面对的是真问题。

**第一步：先分清是「耗竭」还是「抑郁」**（30 秒）
问一句：「如果不做这些照顾的事，你会不会好一点？」
- 会 → 更像耗竭，本卡适用
- 不会，做什么都没劲、持续两周以上 → 可能是抑郁，建议专业评估，本卡不替代

**第二步：换挡（共情 → 关怀）**（3 分钟）
1. 说明：你现在的状态是「跟着一起痛」，不是「托住对方」
2. 给一个呼吸动作：**吸气时，把关怀给自己；呼气时，把关怀给对方**
3. 强调：这不是分心，是让自己站得稳一点，才能继续在场
4. 若用户说「我顾不上自己」→ 回应：「你垮了，对方更没人管」——
   **这是功能性的理由，不是道德要求**

**完成标准**：用户能做出一次「吸气给自己、呼气给对方」。

**第三步：给「接受」一个小练习**（3 分钟）
1. 问：「最近有人对你好吗？哪怕很小的事。」
2. 若用户想推掉 → 不要求他接受，只要求他**不立刻拒绝**：
   「先收下，什么也别说，看看会发生什么」
3. 说明：接受不是欠债。它是让关怀能流动。

**完成标准**：用户愿意在下一次被关心时，先停三秒再回应。

**判停点**：
- 若用户已出现明显功能受损（无法工作、无法照顾自己）→ 建议专业支持 + 喘息服务，
  本卡不替代实际减负
- 若用户提到对**被照料者的怨恨** → 不评判，明确「怨恨不等于不爱，
  它是耗竭的信号」；这是最需要被正常化的一点
- 若涉及对老人/孩子/病人的照护安全风险 → 转介社会资源

## B · 边界

**不要用这张卡的情形：**

1. **用户有自伤/自杀意念** → 危机硬停（照料者自杀风险常被忽略，须优先筛查）
2. **用户是抑郁而非耗竭** → 建议专业评估，不把抑郁解释成「你付出太多」
3. **用户实际需要的是减负**（没有人手、没有钱、没有喘息）→
   心理技巧解决不了结构问题，应先谈资源，不要用「换个心态」替代实际帮助
4. **涉及照护对象的安全风险** → 转介，不做心理化处理

**书中警告过的失败模式：**

| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| 只给不收 | 拒绝一切关心 | 单向付出 → 耗竭 → 隐秘怨恨 → 羞耻 |
| 停在共情 | 跟着一起痛 | 共情疲劳，不可持续 |
| 抢着解决 | 急着给建议 | 常是在回避自己的共情之痛 |
| 把「关怀自己」当成自私 | 一休息就内疚 | 垮了对方更没人管 |

**护栏硬约束（本卡专属）：**
1. **不把「照顾自己」道德化** —— 用功能性理由（你垮了对方更没人管），
   不用道德理由（你应该爱自己）
2. **不评判对亲人的怨恨** —— 只做正常化（耗竭信号）
3. **不用心理技巧替代实际减负** —— 缺人手、缺钱、缺时间时，先谈资源
4. **照料者自杀风险要主动筛查** —— 这个群体风险高但常被忽略
5. 不做诊断

**这张卡最容易犯的错**：把结构性问题心理化。
对方一天 20 小时照护、没有一分钱支持，你说「你要先照顾自己」——
这不是帮助，是加重负担。
**先问资源，再谈心态。**
