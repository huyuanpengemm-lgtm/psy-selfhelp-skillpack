## R · 原文依据

- **出处**：第 20 章「自我关怀与人际关系中的愤怒」（满足未被满足的需求、有力的关怀两个练习）；第 18 章（人际冲突中的即时自我关怀）
- **书中内容**：把愤怒视为一个有三层的结构——表层是愤怒，下面是更柔软的情绪（受伤、害怕、羞耻），

- **关键术语**：三层剥壳；柔软情绪；未被满足的需要；有力的关怀

## I · 核心洞见

> **依据等级 B（成文方法）**——本段是对方法的理解与综合，**不是研究结论**。
> 对用户输出时须降级为「这本书的看法是……」，不得直接说成事实。
> 若其中某条是本项目的推断，须标「项目补充」。


**这张卡不评价「你该不该生气」，只处理「愤怒下面是什么」。**

这一点必须先划清，否则会变成道德劝告。愤怒本身不是问题；
问题在于它经常**盖住**更软弱、更难承认的东西。

**三层结构：**

```
第一层：愤怒（"他怎么可以这样"）
    ↓ 问：如果愤怒是在保护什么，它保护的是什么？
第二层：柔软情绪（受伤 / 害怕 / 羞耻 / 失望）
    ↓ 问：我本来希望发生什么？什么没被给到？
第三层：未被满足的需要（被尊重 / 被看见 / 被公平对待 / 安全感）
```

**为什么不能停在第一层**：停在愤怒，只能做两件事——攻击或压抑。
攻击破坏关系，压抑转向自己（抑郁、躯体症状）。
而第三层是可以被满足的，至少可以被自己部分满足。

**「有力的关怀」是这张卡的第二个要点**：
自我关怀不等于退让。设立边界、说不、离开一段有害关系，**都是关怀**。
很多人以为「关怀」就是「忍」，那是把它做成了「不许生气」。

## A1 · 书中案例

**案例一：发泄无效的长期愤怒**
一位学员被亏待后长期愤怒，捶枕头、大喊都试过，无效。
书里的路径是三层下拆：愤怒 → 受伤（「我这么多年真诚付出，却被这样对待」）
→ 需要（被尊重）。
然后**直接对自己说「我尊重你」**。
**关键细节**：第一次说几乎一定是空洞的，要两个条件同时具备才松动——
① 当成真的再说一遍 ② 接上具体证据（自己多年真诚的付出）。
**方法要点**：关怀话语落地需要「当真 + 证据」，缺一个就只剩口号。
这一条直接解释了用户为什么「说了好话却没感觉」。

**案例二：把愤怒转向自己**
另一位学员从不表达愤怒，但长期情绪低落、身体不适。
书里的解释是：愤怒没有消失，只是转向了内部。
**方法要点**：不表达的愤怒不会消失，它换一个方向继续。

## A2 · 触发条件

**用户会在这些情境下需要它：**

1. 说「一点就炸」「控制不住发火」
2. 说「我从来不生气」，但长期低落、疲惫、身体不适
3. 生气之后又后悔、自责
4. 反复想「他凭什么这样对我」
5. 问「我是不是太敏感 / 太小气」

**语言信号**（中／英）：
- 「一点就炸」「火压不住」「生气完又后悔」「我是不是太小气」
- 「我从来不生气」「但我心里堵」
- "I have a short fuse" / "I never get angry but I feel awful" / "am I overreacting"

**与相邻卡的分工**（初稿，阶段 3 定稿）：
- 与**《控制你的愤怒》分册**的区别：那张卡处理「怎么表达」（时机、措辞、边界），
  这张卡处理「愤怒下面是什么」（三层剥壳）。**两者可串联，不可替代。**
- 与**卡 7** 的区别：卡 7 处理一般情绪，卡 9 专处理愤怒这个有保护功能的情绪。
- 与**卡 8** 的区别：卡 8 处理「骂自己」的声音，卡 9 处理「对别人」的愤怒
  （虽然两者都可能转向内部）。

## E · 执行步骤


> **⚠️ 五种问法同等处理**：本条红线对第三人称（「我朋友/我妈…」）、
> 合理化（「这算成长吧」）、误信（「书上说能治愈」）同样生效。
> 判断依据是**这件事该不该做**，不是**他用什么句式问的**。

**第一步：先确认「生气是允许的」**（一句话，不可省）
明确说出：**「生气本身不是问题。我不评价你该不该生气。」**

这一步是前置条件。如果用户感到自己正在被评判，后面所有步骤都会变成辩解。

> ⚠️ 本卡提问较多（四步各有一问）。**一次只问一个，问完给内容再往下**，
> 不要连发。若用户已经主动说出柔软情绪，跳过对应提问。

**第二步：剥第一层 → 第二层**（3 分钟）
1. 问：「如果这份愤怒是在保护什么，它保护的是什么？」
2. 常见答案：保护自尊、保护不被再次伤害、保护某个重要的人
3. 再问：「**在生气之前，或者生气底下，你感觉到了什么？**」
   - 给选项：受伤 / 害怕 / 失望 / 羞耻 / 无助
4. 若用户说「就是生气」→ 不勉强，改问「如果对方现在真诚道歉，你会怎么样？」
   （通常这时柔软情绪会浮现）

**完成标准**：用户说出一个比「愤怒」更软弱的词。

**判停点**：若第二步引发强烈情绪（哭、身体发抖）→ 停止剥层，转卡 3 或卡 4。

**第三步：剥第二层 → 第三层**（3 分钟）
1. 问：「你本来希望发生什么？什么没被给到？」
2. 帮它落成一个需要的词：被尊重 / 被看见 / 被公平对待 / 安全感 / 被信任
3. **不要评判这个需要是否合理** —— 需要本身没有对错

**完成标准**：用户说出一个具体的需要。

**第四步：由自己部分满足**（3 分钟）
1. 说明：这个需要最理想的满足来自对方，但对方不一定给
2. 问：「**在这个人之外，你自己能不能给一点？**」
3. 给一句可说的话（对着自己）：如「我尊重你」「你的付出是真的」
4. **提醒两个条件**：① 当成真的说 ② 接一个具体证据
   - 例：「我尊重你。—— 这些年我从没在背后说过人坏话，这是真的。」

**完成标准**：用户说出了一句自己觉得「有一点点真」的话。
**不要求「进入心里」** —— 那需要反复。

## B · 边界

**不要用这张卡的情形：**

1. 🔴 **存在亲密伴侣暴力或控制型关系** → **本卡不适用**，转介。
   三层剥壳会让受害者更容易归因于自己（「原来我生气是因为我受伤」），
   反而削弱离开的动力
2. **用户是施暴方或在控制他人** → 本卡不适用。
   「理解愤怒下面是什么」会被用来合理化施压行为
3. **用户在急性愤怒中**（刚吵完架、正在发抖）→ 先做降温（卡 3），不做剥层
4. **用户有自伤/伤人意图** → 危机硬停

**书中警告过的失败模式：**

| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| 做成「不许生气」 | 压抑、讨好、转向自己 | 情绪不消失，只改方向，易致抑郁 |
| 停在第一层 | 反复发泄（捶枕、大喊） | 发泄不解愤怒，只强化唤醒 |
| 把「理解」做成「合理化对方」 | 「他也不容易」 | 剥层的方向是看自己，不是替对方开脱 |
| 把关怀做成退让 | 「我要包容」 | 关怀包括设立边界和保护自己 |

**护栏硬约束（本卡专属）：**
1. 🔴 **家暴 / 控制型关系不适用** —— 命中即转介，不做任何剥层引导
2. **不评价愤怒的合理性** —— 不说「你反应过度」或「你生气是对的」
3. **不要求原谅** —— 宽恕不是必做项，也不是终点考核
4. **不分析对方的动机** —— 只处理用户自己的三层
5. 涉及暴力念头 → 危机筛查

**这张卡最容易犯的错**：滑向「其实你生气是因为你脆弱」这种解读。
这句话在正确的语境里是洞见，在错误的人身上是**剥夺其愤怒的正当性**。
**判据**：如果用户听完之后觉得「我不该生气」，那就用错了。
正确效果是「我生气是有原因的，而且我知道我在要什么」。
