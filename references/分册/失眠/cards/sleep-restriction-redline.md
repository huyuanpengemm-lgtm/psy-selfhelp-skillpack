## I · 核心洞见

> **依据等级 B（成文方法）**——本段是对方法的理解与综合，**不是研究结论**。
> **本册含大量项目补充，须标「项目补充」。**

**这是本册最有效、也最危险的一项。**

**有效**：卧床与睡着贴得越近，睡眠确实越集中。
**危险**：它的作用机制**本身就是让睡眠变少**——而睡眠减少正是若干情况的触发因素。

### 四类禁忌（写死）

| 禁忌 | 为什么 |
|---|---|
| **双相 / 有过「睡得很少却精力特别好」的时期** | 睡眠减少是躁狂的触发因素 |
| **癫痫** | 睡眠剥夺降低癫痫阈值 |
| **重度抑郁 / 有伤害自己的想法** | 会短期恶化心境 |
| 发作性睡病 / 未治的睡眠呼吸暂停 | 白天嗜睡加重，且会掩盖病情 |

**处置**：命中任一 → 不做，只给睡眠教育 + 就医。
**不确定 → 按命中处理。** 不允许「先试一下，不行再停」。

**理由必须说出来**：
> 这项技术的起效代价就是睡眠减少，而风险恰恰来自睡眠减少本身——
> **试错与伤害是同一步，没有安全剂量。**

## A1 · 书中案例

**案例一：一位来访者的算术（c09/c10）**
他会算：「躺着的时间比睡着的多出一截，那我少躺点不就行？」

**这就是最容易伤人的那一句话**——没有禁忌词、没有宣告，是一个半步正确的算术。

## E · 执行步骤

**① 先承认算术，再指出机制**（不给数字）

> 「你这个算法是对的——卧床和睡着贴得越近，睡眠确实越集中。
> 但这类方法的作用机制，本身就是让睡眠变少。」

**到此为止。** 不出现幅度、阈值、上床/起床时刻、卧床下限。

**② 禁忌筛查（问，不猜）**

双相或「睡得特别少却精力特别好」的时期？癫痫？持续情绪低落或有伤害自己的想法？
打鼾响 + 白天控制不住犯困 + 晨起头痛？发作性睡病？**在吃什么药？**（→ 同时走入口第 0 层）

**③ 不确定即不做**

「不清楚 / 应该没有 / 好多年没犯了」→ **一律按命中**。不得用「先试一下」绕过。

**④ 方向性许可：不发放**

问「我能不能少躺一点」→ **不答能、不答不能、不答可以试试**。
只给两件低危替代：**固定起床**（就寝不固定）、**睡不着且难受就离床**。

**⑤ 拒答话术（固定）**

> 「具体压到多少我不给——这个数要由给你做过评估的人定。
> 我给的任何数字，到你手上都会变成你自己执行的处方。」

**反向（已在做）**：先问 ②；命中 → 建议停止，且**不要自行「往回加时间」**（反弹也需监督）→ 就医。

## B · 边界

**不要用这张卡的情形：**
1. 用了这张卡就以为可以自己做 → **本卡的目的正相反**：让人知道为什么不能自己做
2. 用户已确诊双相/癫痫 → 直接转诊，不讨论

**书中警告过的失败模式：**
| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| **x09 自行睡眠限制** | 「我少躺两小时试试」 | 起效与伤害同一步 |
| **x02 延长卧床** | 「多躺会儿总能睡着」 | 分母变大，睡得更碎 |
| **x10 当放松训练** | 「这是个放松方法」 | 机制不是放松，是压睡眠 |

**护栏硬约束：**
1. 🔴 **零数字**：幅度、阈值、时刻、下限，一个都不给。
2. 🔴 **方向性许可不发放**（不说「能」「不能」「可以试试」）。
3. 🔴 **不确定即按命中**。
4. 🔴 **阻断条款 D**：不得出现「睡眠剥夺 / 整夜不睡 / 缩短睡眠可改善情绪」的组合表述。
5. **≤200 字**。

**正确的收尾**：这个方法的门槛不在操作，在有人看着。这里没有那个人。
