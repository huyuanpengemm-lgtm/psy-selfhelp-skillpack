# 失眠

> **本分册是心理自助性质的工具，不构成诊断、治疗或用药建议。**
> 如有自伤念头请拨 **12356**（24 小时）。

---

## 入口三层（顺序不可颠倒）

### 第 0 层 · 强制询问（x08）

**只要话题涉睡眠——入睡难 / 夜醒 / 早醒 / 睡不实 / 梦多 /「怎么才能睡好」——
给任何建议之前，先问同一句：**

> 「有两件事我需要先确认一下：你最近有没有在用安眠药、镇静药，或者其他帮助睡眠的处方药？
> 另外，睡前会不会喝酒，大概什么量？」

🔴 **两个问题必须同一句问出。分开问 = 漏检，这就是这一层的全部要点。**

**两项都为是 → 立刻、明确、不软化**：
> 「这两样一起用会互相放大对呼吸的抑制，**是有可能致命的组合**。
> 这不是『少喝一点』的问题，是不要同时用。」
不给剂量换算、不说「隔几小时就安全」、不说「少量没事」。
唯一动作：找医生，并嘱咐「去的时候把『两样都在用』原样说，不要说成两件事」。

**禁止表述**：✗少量红酒助眠 ✗睡前一两杯没关系 ✗隔开两小时就行 ✗任何药名+剂量

### 第 1 层 · 筛查放行

| 命中 | 去向 |
|---|---|
| 打鼾响 + 呼吸停顿 + 白天嗜睡 + 晨起头痛 | **睡眠呼吸暂停 → 就医** |
| **早醒 + 情绪低落 / 兴趣减退 / 精力下降 / 自责** | **抑郁 → 转诊**（早醒偏抑郁，入睡困难偏焦虑）|
| 夜间心悸惊醒 | 惊恐 → 焦虑分册 |
| 控制不住要睡着（不是累）| 发作性睡病 / 严重睡眠不足 → 就医 |
| 腿部不适、晚间加重、活动后缓解 | 不宁腿 → 就医 |
| 长期服药 / 换药 / 自行停药 | 医生 |

### 第 2 层 · 三问分型

| 问 | 答案 → 卡 |
|---|---|
| ① 最近一次睡得最香是在哪？ | 能（别处睡得好）→ **卡 2**（场所型）|
| ② 躺下时身体紧，还是脑子停不下来？ | 紧/在努力 → **卡 1**；念头多 → **卡 3** |
| ③ 最近是太忙还是太空？ | 太忙 → 减负；太空 → **卡 5** |

**⚠️ 卡 1 与卡 2 的建议方向相反**（床上看书 vs 床上不许看书），
原文明确「两个方案不能同时套」。**分错型会把两套同时给出去、互相抵消。**

## 🔴 三条最硬的

### 一、卡 8 的「方向性许可」不发放

用户问「我能不能少躺一点」→ **不答能、不答不能、不答可以试试。**
只给两件低危替代：固定起床、睡不着且难受就离床。

**不确定即按命中。** 理由必须说出来：
> 起效代价就是睡眠减少，而风险来自睡眠减少本身——**试错与伤害是同一步，没有安全剂量。**

### 二、全册零数字

「20 分钟起来」**不是这本书的**（书里判据是「不能入睡」）；
睡眠效率 85%/90%、压缩幅度、卧床下限，**一律不给**。

### 三、「睡得少但白天正常」不算失眠

四条功能核对（起床困难 / 靠闹钟 / 看电视就睡着 / 需要周末补觉）**≥2 条**才算不足。
**条件从句不能省**，否则会变成反向断言。
