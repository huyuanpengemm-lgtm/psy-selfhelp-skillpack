# 跨诊断（UP）

> **本分册是心理自助性质的工具，不构成诊断、治疗或用药建议。**
> 如你正处于危机中，请拨打全国心理援助热线 **12356**（24 小时），
> 或前往正规医疗机构精神科/心理科就诊。

**版本**：v0.1 · 5 张卡 · 单一书源《情绪障碍跨诊断治疗的统一方案·自助手册》。

## 为什么这一册只有 5 张卡

**这是算出来的，不是漏掉的。**

本书的六个章节（情绪反射弧、思维陷阱、情绪回避、情绪驱动行为、暴露、认知重评）
**已经在「情绪调节·抑郁」和「焦虑·惊恐」两册里了**——抑郁册把本书当第二书源用了整整六章。

所以本册只留**别的册接不住的五个开口**：

```
别人已经有的                     本册只剩
────────────────────────────────────────────────
暴露怎么排台阶                →  焦虑册（整块让出去）
回避为什么维持、怎么撤        →  抑郁册卡 3 / 5
想法怎么检验                  →  抑郁册卡 1 / 2
正念觉察怎么练                →  正念册（整章让出去）
────────────────────────────────────────────────
没人接的：
「我根本不想改」              →  卡 1
「说不清，就是一整团」        →  卡 2
「连好事也不敢」              →  卡 3
「知道要改，不知先做哪步」    →  卡 4
「好起来以后」                →  卡 5
```

**5 张各自对应一个别的册接不住的开口。** 凑到 8 张，只能靠拆细或重复。

## 🔴 红线区（本册最容易好心做错的四件事）

### 一、不给诊断

本书第一章逐条列了各障碍的症状。**那不是让你对号入座的。**
本册**不出现任何障碍名**，也不问「你符合几条」。

### 二、药物零内容

本书有一整章讲药物治疗。**本册整章未取。**
任何「该不该吃药」「吃什么药」「能不能停」→ 一律推回医生。

### 三、不做量表评分

本书第三章有两份五点量表和一个进展折线图。**本册不取。**
**给分就是给判决**，而且分数会被当成验收——「我 17 分，说明我没好」。

### 四、不给症状诱发操作

本书第十一章有一组练习，
用来主动制造心跳加速、头晕、发空这类感觉。

**本册不给这组操作，也不描述怎么做。** 理由与焦虑册一致：
这类练习在有人指导时是标准做法，**独自做有晕厥、跌倒与惊恐发作的风险**。
本册只在卡片里承认「身体那一块存在」，不给练法。

## 路由：先进哪一张

```
用户开口
   ↓
① 危机筛查（_shell/02）        ← 命中则硬停，不做任何分析
   ↓
② 他要的是「做不做」还是「怎么做」？
      做不做 → 卡 1（想改又不想改）
      怎么做 → 继续
   ↓
③ 他说得清是哪件事吗？
      说不清、一整团         → 卡 2
      说得清，是怕某个场合   → 焦虑册
   ↓
④ 他要躲的，是难受还是舒服？
      舒服（不敢放松/不敢高兴） → 卡 3
      难受（低落、不想动）      → 抑郁册
   ↓
⑤ 已经决定要改，缺第一步  → 卡 4
⑥ 已经在做，怕停          → 卡 5
```

🔴 **卡 1 必须先于卡 4。**
书里的顺序是先算账、再排步骤。反过来做，用户会在「其实我不太想改」上反复失败，
然后得出「我连这个都做不到」。

## 五条判据（本册最有用的部分）

### 1 · 「不改」不是零成本

> 用户：「改了也没用，还不如现在这样。」
> 问：**「现在这样，替你挡住了什么？」**

答得出 → 那是他在选的成本，不是在忍的命运。
答不出 → 他还没算过账，先别谈改变。

### 2 · 说不清时，不要问「为什么」

> 用户：「我说不清，就是一整团。」

**「为什么」在那种时候一定问不出东西。** 换成三句：想什么、哪儿难受、做了什么。

### 3 · 躲的是难受，还是舒服

> 问：**「如果今天一定不会出事，你敢不敢什么都不做，就待着？」**

「不敢」→ 躲的是舒服（卡 3）。
「那我就空得慌 / 更难受」→ 躲的是难受（抑郁册）。

**这一句是全册最能分开两类人的地方。**

### 4 · 目标是动作还是状态

> 判据：**能不能二分——做完 / 没做完。**

「更自信一点」不能二分，「下次开会我说一句」能。
不能二分的，不是目标，是愿望。

### 5 · 回避分和痛苦分不是一回事（我们的说法）

书中排「要接近什么」时记**两个**分：有多想躲、有多痛苦。
这两件事常常不一致：**有人很怕却从不躲，有人不太怕却一直在躲。**

所以**「很怕」不等于「该先练」**。
（本册只给这一句判据，**不给表、不排顺序**——排顺序是焦虑册的事。）

## 与相邻分册的边界

| 相邻 | 分工 | 会不会打架 |
|---|---|---|
| **情绪调节·抑郁** | 它用本书的六章讲「反复的机制」与「想法怎么检验」；本册只用本书**没被用掉**的部分 | 不打架，但**同一本书不能两册各讲一半**：用户要检验想法 → 只去抑郁册 |
| **焦虑·惊恐** | 它管暴露的整块规则（分级、升级、退出）；本册**不排台阶、不给强度、不判过没过** | 🔴 **两册的暴露判据不同，不得互引**。焦虑册按焦虑高度排；本册按回避与痛苦两个分看 |
| **正念·抑郁 / 正念减压** | 本书第七章的觉察练习原书自陈改编自正念认知疗法，**本册整章不取** | 不打架。要练觉察 → 去正念册 |
| **DBT** | 都有「做一个与冲动相反的动作」，但**判据不同**：本册看「与当下情境是否相符」，DBT 看「这个行为有没有害」 | 🔴 同名不同判据，不可混讲 |
| **ACT** | ACT 问「回避是否妨碍你过想要的生活」；本册问「这个回避本身花了多少成本」 | 不打架，一次只用一套 |

## 依据等级

| 级 | 本册 |
|---|---|
| **A** | 跨诊断统一方案作为一类方案有随机对照试验支持（方案级，**非本书自做的试验**） |
| **B** | 五张卡的全部方法内容——都能回指到原书某章 |
| **C** | 「给情绪命名」「把大目标拆小」这类多来源共有动作 |
| **D** | 红线四条、路由顺序（卡 1 先于卡 4）、第 5 条判据（双轴不一致）——**项目补充** |
| **E** | 无 |

**对用户输出**：B 级说「这本书的做法是」；D 级说「这是我们加的一条」。

🔴 **A 级是方案有证据，不是每个动作有证据。**
「决策工作表有用」不能写成「研究证明填表能提升动机」。

## 一处留痕

本书第 2 章说「同时做两套治疗会互相冲突」，第 12 章又说「暴露做不动时回去看决策工作表」。
书里自己的顺序是：**先决定做不做，再开始做。**
本册按这个顺序排路由（卡 1 先于卡 4）。读者若对照原书，请注意这一点。
