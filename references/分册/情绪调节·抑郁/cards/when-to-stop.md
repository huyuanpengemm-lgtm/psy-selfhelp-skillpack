## I · 核心洞见

**这张卡处理的是「什么时候该停、该换、该找别人」——比任何技术都容易做错。**

### 三个判断

**一、成功标准错了，会把有效当无效**

| 错的标准 | 对的标准 |
|---|---|
| 不焦虑了 | **焦虑来时知道怎么应对**（p06）|
| 情绪降了 | 做过之后，下次还敢做 |
| 想通了 | 生活里那件事有没有变 |

**二、复发苗头 vs 正常波动：四条一起看**（p09）

| 判据 | 说明 |
|---|---|
| ① 持续 | 好几天都一样，不是一两小时 |
| ② 跨域 | 不只一件事，是好几件都不对 |
| ③ 熟悉 | 和上次发作前的路数一样 |
| ④ 功能 | 吃饭睡觉工作开始受影响 |

**一条都不满足 → 是波动，不要当复发处理。**
四条都满足 → 建议找专业的人，**不自己硬练**。

**三、不要同时上两套情绪治疗方法**（p10）

CBT、MBCT、ACT、自我关怀——同时用会互相抵消（最典型：本册要求辩论，MBCT 要求不辩论）。
**一次只用一套。**

## A1 · 书中案例

UP 在开篇就说明本方案的适用边界：它针对的是有一定基础的、能进行自我观察的人；
急性期、功能严重受损时不适合开始。
**方法要点**：**开始前的判断，比开始后的努力重要。**

## A2 · 触发条件

**用户会说**：「做了没用」「我是不是该吃药」「怎么知道要复发」「我在同时学好几个方法」

**与相邻卡**：任何卡做到第 3 次仍无进展 → 转本卡。

## E · 执行步骤

**第一步：先问是哪种「没用」**（1 分钟）

| 用户说 | 实际是 | 去哪 |
|---|---|---|
| 「做完还是难受」 | 标准错了（期待归零）| 说明 p06，回原卡 |
| 「做了几次没变化」 | 可能是强度/剂量问题 | 回原卡调，或转卡 2 |
| 「我做了但什么都没改变」 | 只做了认知没做行为 | 转卡 4 / 卡 5 |
| 「越来越糟」 | **可能超出自助范围** | 进第二步 |

**第二步：四条判据**（用于「越来越糟」）

逐条问：持续几天？几件事？和上次一样吗？吃睡工作受影响吗？

- **≥3 条** → 建议专业评估（**给 12356，不自己继续练**）
- **1–2 条** → 降剂量、回到最轻的动作
- **0 条** → 是波动，正常，不用处理

**第三步：确认只用一套方法**

> 「你现在除了这个，还在用别的方法吗？」

若同时用两套 → 建议**先停一套**，说明原因（互相抵消）。

**判停点**：
- 用户问「要不要吃药」→ `_shell/09` 医疗边界：**推回医生，不给判断**
- 用户说「我练了很久还是不行」→ 先看是不是标准问题，再考虑转介

## B · 边界

**不要用这张卡的情形：**
1. 🔴 涉自伤/自杀 → 危机硬停
2. 用户只是想要一句肯定 → 本卡给判断，不给安慰，先说明
3. 已经明确在急性期 → 直接建议专业治疗

**书中警告过的失败模式：**

| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| 用情绪分数验收 | 「怎么还是 70 分」 | 分数是状态，不是成绩 |
| 把波动当复发 | 一天不好就恐慌 | 会加速恶化 |
| 同时上两套方法 | CBT + 正念 一起练 | 转向相反，互相抵消 |
| 硬练 | 「再坚持一下」 | 有些情况该转介，不该加力 |

**护栏硬约束：**
1. 🔴 **不给「练多久会好」的时间预期**。
2. 🔴 **不给药物建议**，一律推回医生。
3. 🔴 **四条判据不许简化成一条**（只看情绪分数是错的）。
4. **不承诺「坚持就有效」**。
5. **≤200 字**。

**正确的收尾**：判断「该不该继续」，比继续本身更重要。
