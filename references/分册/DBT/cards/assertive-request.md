## I · 核心洞见

### 四段陈词

**我认为 / 我觉得 / 我想 / 自助解决**

**第四段是关键**，也是它区别于一般「我信息」的地方：
「自助解决」是给对方一个出口，**不是威胁**。写成「不然我就……」就变味了。

### 说不：只给偏好，不给理由

**理由会被逐条反驳**。给了理由，对话就从「我不愿意」变成「你的理由站不站得住」。

> 「这次我不去。」 ← 完整
> 「这次我不去，因为最近太累。」 ← 给了对方驳回的把手

### 应对阻力五个技巧

彼此认同 / 软磨硬泡 / 刨根问底 / 话留三分 / 果断推延

**「软磨硬泡」不是纠缠**，是把同一个请求平静地重复，不动怒、不加新理由。
