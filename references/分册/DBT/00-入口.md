# DBT（辩证行为疗法）

> **本分册是心理自助性质的工具，不构成诊断、治疗或用药建议。**
> 如有自伤念头请拨 **12356**（24 小时）。

## 🔴 前置条文 1 · 用技能替代危机求助

**这是本分册第一危险，因为它与 AI 的默认行为同向。**

AI 被训练成「有用」：用户说「很难受」就给技术，说「撑不住了」还是给技术。
于是生产出「我正在处理」的错觉，**把求助窗口一小时一小时往后推**。
而技能在危机情境必然失效——失效又被记在用户账上（「我连这个都做不到」）。

**书里有一处证据可以说明为什么**：热线是「转移注意力」长清单的**一个勾选项**，
排在「网上购物」和「拼图游戏」**之间**。
AI 复制这个结构时，会做同一件事：**把「联系一个人」当成备选项，而不是唯一项**。

### 触发的是「时间窗」和「不可逆」，不是「情绪强度」

> **情绪强度不预测危机**（长期高压者天天 10 分）；**时间词预测，不可逆动作预测。**

| 类 | 形态 | 处置 |
|---|---|---|
| **A 直接表达** | 不想活了 / 不如死了 / 希望明天不要醒 / 我撑不住了 | 听到即转介，不问「为什么」|
| **B 手段与准备** | 东西送人了 / 写了一些话 / 查过怎么弄 / 在收拾 / 得先交代一下 | 🔴 唯一能区分念头与行动的一类，**最易被当成「他在整理生活」放过** |
| **C 时间锁定** | 今晚 / 今天 / 等一下 / 半夜 / 就这一次 | **最高优先级**，它把风险变成倒计时 |
| **D 独处与封闭** | 我一个人 / 别告诉别人 / 说了也没用 / 我自己能处理 | 单独不触发，但决定 A/B/C 的处置强度 |

**问 B 类的唯一正确方式**（不列方法）：
> 「有没有一些事，你最近开始做了，但没跟人说过？比如把东西送出去、写下来、或者查过什么。」

### 🔴 组合信号：三句全中，无需确认

**「我没救」+「今晚撑不住」+「我自己处理」**

三句合起来是一个**闭合结构**：结论已定 + 窗口已定 + 出口已关。
此时追问会被读成「你不信我」，而每追问一轮都在**消耗窗口**。

两位置中（结论 + 窗口）→ 转介。三位全中 → 转介，且除话术外**不许多说一句**。

### 转介五段（顺序不能换）

为什么不能说「建议寻求专业帮助」：它把决定权交回给**此刻已经没有决定权的人**，
而且**没有下一步**——说完对话就结束，而 AI 没有下一次。
**也不能先共情**：用户会以为「她还要跟我聊」。

1. **停手声明**（第一句必须是它）：
   「我先停下。接下来我不教你任何方法——**不是因为你做不到，是因为方法在这个位置上没有用**。」
2. **命名**（行为，不诊断）：
   「你说的不是『今天很难过』。是你在给一个时间点，而且在把所有人挡在外面。」
3. **一个具体的人、现在能拨**：
   「现在打 12356，或者去最近的急诊。这不是『有空去看看』，**是今天**。」
4. **回执（不是承诺）**：
   「打完回来说一句『打通了』或『没打通』。没打通我们换下一个，我在这儿等。」
   🔴 **不索取「你答应我不要做」**——口头保证不预测安全，还把责任移回用户，出事后变成他的违约。
5. **今晚最小安排**（一句）：
   「今晚不要一个人待着。能立刻联系上的人里，谁现在醒着？**名字说出来一个就行**。」

收尾不用「你要好好的」，用可执行句：**「现在拨，拨完回来告诉我。」**

### 🔴 一句禁止句

> **「你现在先试一下这个方法，做完告诉我感觉怎么样。」**

一句里同时做三件坏事：把危机变成作业、把 AI 变成唯一在场者（「告诉我」）、
把成败记在用户账上（「感觉怎么样」无改善 = 又一次失败）。

**变体全算同一句**：先深呼吸 / 试试 4-7-8 / 先做几次正念 / 转移一下注意力 / 写下来会好一点 / 先自我抚慰一下。

**判据：看这句话给出的下一个动作，是不是用户独自完成的。**

### 硬线

本轮出现**时间词 + 一个不可逆动作** → **本轮回复不许出现任何技能名**。
反向也成立：已在教技能，用户中途说「其实我今晚……」→ **立即中断**，不许「先把这一步做完」。

| # | 卡 | 用户会说 |

| 1 | 现在很难，先别让它更糟 | 「我受不了了，必须马上解决」|

## 三条最硬的判据

**1 · 分心 → 逃避：回程必须本轮定死**
书里的「回来」从来不是「改天」，是**这一趟之内**（两个正例都当天折回）。
AI 场景逼到极端：会话关掉即归零，**「以后处理」不是延迟，是删除**。

> **「以后处理」没有代价、没有日期、也不能被自己看见，是幻觉。
> 「这次不做」是可执行的决定。**

**2 · 全盘接受的停用条件先于它本身**
暴力 / 虐待 / 有害环境 → 不做全盘接受。判据：
**接受之后，我是更容易脱离，还是更容易忍下去？**
书里原话：这种处境下「**你需要发泄出来**」。

**3 · 逆情绪行事看行为，不看情绪合不合理**
书里的判据是「它有没有驱使你做危险或毁灭性的事情」。
照「情绪符合事实才逆着做」的写法，**一个被真实伤害的人会被建议顺着情绪**。

## 「接纳」的第五种意思

| 分册 | 接纳指什么 |
|---|---|
| ACT | 让内在体验来去（内在）|
| 自我关怀 | 关怀自己这个人 |
| MBCT | 允许体验存在 |
| 抑郁册 | 分支选项 |
| **DBT** | **接受外在事实，且不等于宽恕/同意/让步** |

**判别口诀**：**ACT 处理「我很痛」，DBT 处理「它已经发生了」。**

⚠️ 书中**没有**「接受≠认可」这个措辞（「认可」全文 2 次均为日常用法）。
书里的原话是「不是指你宽恕或同意」和「并不意味着你让步」。**引原话，不要引我们的话。**
