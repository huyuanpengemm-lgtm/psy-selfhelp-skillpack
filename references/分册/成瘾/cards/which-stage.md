## I · 核心洞见

> 依据等级 B（成文方法）——本段是对方法的理解与综合，不是研究结论。「三句话判阶段」与「谁在等 / 谁在推」为 **D（项目补充）**。

**同一个动作，在不同阶段是帮忙或帮倒忙。**

### 两句打架的句子，其实不打架

| 书里的句子 | 说的是**谁** | 意思 |
|---|---|---|
| 「不能过早地劝说一个成瘾者戒瘾」 | **别人**在推 | 推早了，人会消失 |
| 「你永远不会觉得自己准备好了」 | **他自己**在等 | 那个时刻不会来 |

**判别只问一句：现在是谁在等 / 谁在推。**

### 三句话判阶段（我们的说法）

1. 「你觉得这件事**是个问题**吗？」——不觉得 → 前注意
2. 「你**想过**要改吗？」——想过没动 → 注意
3. 「你**最近为它做过**什么？」——做过一点 → 准备 / 行动

### 目标是可谈的，但条件硬

书里对减量的立场是**有条件的**：减量可以算进步（前提是没有严重躯体问题、精神问题或由使用引起的其他问题）；但若已有依赖，「节制使用」可能不是合适的目标。

> **判据**：目标合不合适，由「有没有躯体依赖 / 并发症」决定，不由「你够不够努力」决定——而这需要评估，不是自助能定的。

## A1 · 书中案例

**减量被叫胜利，也被叫「太急」**：用量降得很低，被称「一种胜利」；同一段又承认当初撤得太快。**方法要点**：减量是真进展，**但速度本身也是风险**。

**「我还没准备好」**：回答是「你永远不会觉得自己准备好了」。**方法要点**：这句是对**本人**说的；对家人说，等于给拖延盖章。

## A2 · 触发条件

**用户会说**：「我还没想好要不要戒」「我先减量行不行」「我家人天天说我，我烦死了」「我戒了两次都回去了」。

## E · 执行步骤

1. **先判是谁在说话**：他想改，还是别人要他改？这一句决定后面全部。
2. **三句话定阶段**，只定阶段，不评价。
3. **按阶段只给一件**：前注意 → 不加压，问「它占多大位置」；注意 → 记两笔账（卡 1）；准备 → 定一个不会失败的第一步，先说清「会难受」；行动 → 转卡 2、3，**停用前先过医学边界**；巩固 → 转卡 5、6。
4. **把目标写成可检验的一句**：不写「我要戒掉」，写「接下来这段时间，我和它的关系是 ____」。允许答案是「少一点」。

**判停**：说到具体停用 / 减量节奏 → 转前置条文 1；说到「反正我也活够了」→ 转危机。

## B · 边界

**不要用**：有躯体依赖且正在自己减（先处理医学风险）；被强制送来（阶段模型假设本人有选择权）；家人来问「怎么让他想改」（转卡 7）。

| 失败模式 | 为什么错 |
|---|---|
| 把阶段当量表 | 书里自己说会来回跳；给编号就变成考核 |
| 在前注意阶段给计划 | 人会礼貌答应，然后消失 |
| 把减量说成终点 | 对已有依赖的情形，书里不建议把节制当目标 |

**护栏硬约束：**

1. 🔴 不承诺「完全停用是唯一正确的目标」，也不承诺「减量一定可行」。
2. 🔴 不在用户没开口要改时给行动方案。
3. 🔴 不给减量节奏与停药日程——转医学评估。
4. 正文 ≤200 字：只问「你觉得它是问题吗 / 你想过改吗 / 你为它做过什么」。
