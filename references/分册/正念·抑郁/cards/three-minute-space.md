## I · 核心洞见

> **依据等级 B（成文方法）**——本段是对方法的理解与综合，**不是研究结论**。
> 对用户输出时须降级为「这本书的看法是……」，不得直接说成事实。
> 若其中某条是本项目的推断，须标「项目补充」。


**它不是在让你冷静，是在你和反应之间插入一个空隙。**

这个区别必须讲清，否则它会被做成「深呼吸冷静法」——而那正是最典型的失败模式（x13）。

| | 深呼吸冷静法 | 3 分钟呼吸空间 |
|---|---|---|
| 目标 | 让情绪降下来 | 让你看见自己此刻在什么状态 |
| 做几步 | 1 步（深呼吸） | **3 步，缺一不可** |
| 失败表现 | 没冷静就判失败 | 没冷静也算完成 |
| 对情绪 | 试图消除 | 不试图消除 |

**为什么不能只做第 2 步**（这是全书最独特的一个判断）：

只聚焦呼吸 = **只改变了注意的内容，没改变注意的运作方式**。
你还在用「抓住一个东西不放」的方式对待自己——那还是行动模式。
第 1 步（承认此刻有什么）和第 3 步（铺开到全身）才是换模式的部分。

**三步的作用不同**：

| 步 | 做什么 | 缺它会怎样 |
|---|---|---|
| **1 觉知** | 问「我现在体验到什么？」——想法/情绪/身体感觉 | 直接聚焦呼吸 → 变成逃避当下的强行转移 |
| **2 聚焦** | 把注意力收拢到呼吸 | 跳过 → 心散着，无处落脚 |
| **3 扩展** | 从呼吸铺开到全身与姿势 | 停在呼吸 → 只收拢不回到生活，出不来 |

## A1 · 书中案例

**案例一：把呼吸空间当急救按钮**
有学员只在难受时用，且期待它「把情绪按下去」。没按下去就觉得失败。
书里指出这是把两种用法混了——**回应式的目的是让你在反应前有一刻选择**，
不是消除情绪。

**案例二：呼吸空间后的四条路（f06）**
做完三步之后不是结束，有四条可走：
① **回到生活**（带着刚获得的一点视角继续做事）
② **回到身体**（把注意力放到身体感觉上）
③ **看想法**（把想法当作心理事件）
④ **行动**（做一件此刻需要做的事）

**方法要点**：呼吸空间是门，不是房间。它的价值在于「从门出去」，不在于待在里面。

## A2 · 触发条件

**用户会在这些情境下需要它：**

1. 情绪正当时，需要一个立刻能做的动作
2. 说「我知道要觉察，但不知道怎么做」
3. 反复被同一件事拽走，想要一个「暂停」的办法
4. 事情太多、心很散，落不下来
5. 问「有没有三分钟能做的」

**语言信号**（中／英）：
- 「现在很难受」「静不下来」「脑子很乱」
- 「有没有马上能做的」「几分钟的那种」
- "I need something right now" / "I can't settle" / "a quick practice"

**与相邻卡的分工**：
- 与**卡 1**：卡 1 处理「反复想」，卡 3 处理「此刻就要一个动作」。
- 与**卡 8**：若做完更难受 → 转卡 8，不在这里加码。
- 与**自我关怀分册卡 3**：那个是「给温度」（手放心口 + 三句话），
  这个是「给空间」（觉察三步）。**两者可并用，但不要混讲**。

## E · 执行步骤

**第一步：先定用法**（10 秒）

问一句：**「你是想在固定时刻练，还是现在正难受？」**

- 固定时刻 → 常规式：每天挑 3 个固定点（起床、午间、睡前）
- 正难受 → 回应式：现在就用

**为什么先分**：两种用法的心态不同。常规式是「保养」，回应式是「插空隙」。
混用会导致「我难受时做没用」的误判。

**第二步：三步，各约一分钟**（3 分钟）

**第 1 步 · 觉知**
> 「现在，你注意到什么？——有什么想法？什么情绪？身体什么感觉？」

不要求说清，能说出一样就好。**这一步不评判、不解决。**

**第 2 步 · 聚焦**
> 「把注意力放到呼吸上。不用控制它，只是跟着它。」

走神了回来就行，不需要报告「我刚才走神了」。

**第 3 步 · 扩展**
> 「现在把注意力从呼吸铺开，到整个身体——姿势、脚踩地的感觉、脸部的松紧。」

**完成标准**：三步都做过。**不要求情绪变化。**

**判停点**：
- 若第 1 步就出现强烈情绪或身体不适 → **停止**，只做第 3 步的「脚踩地」，
  或转卡 8
- 若用户说「做完了没感觉」→ 正常，**不要加码**，说「没感觉也算做过了」

**第三步：给一条出口**（30 秒）

做完不要停在那里，给一条路（四选一）：
> 「现在可以选一个方向：回到刚才在做的事 / 关注一下身体 / 看看刚才那个想法 / 做一件此刻该做的小事。」

**为什么必须有这一步**：否则呼吸空间会变成「一个要待够三分钟的地方」，
反而增加负担。

## B · 边界

**不要用这张卡的情形：**

1. **用户在急性情绪峰值** → 先做「脚踩地」这类更简单的稳定化，不做三步
2. **用户有创伤史且未做筛查** → 只做第 1、3 步（外部注意），**跳过闭眼聚焦**
3. **用户期待「做完就好」** → 先说明它不是消除法，再决定要不要做
4. **用户已经练了很多次仍无变化** → 转卡 7（剂量）或卡 9（意图检验），
   不要在这里加时长
5. **有自伤/自杀意念** → 危机硬停

**书中警告过的失败模式：**

| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| **x13 只做第 2 步** | 当成深呼吸冷静法 | 只改内容不改运作方式，仍是行动模式 |
| 当消除痛苦的技术 | 「做完还难受，没用」 | 目标错，会反弹 |
| 做成打卡 | 「今天第三次了」 | 变成考核 |
| 强行闭眼 | 一闭眼就想起不好的事 | 应改睁眼或半睁 |

**护栏硬约束（本卡专属）：**

1. 🔴 **不承诺「做完会平静」**。它不消除情绪。
2. 🔴 **必须给「可以睁眼」的选项**。闭眼不是必要条件。
3. **不给「每天三次」的硬规定**——那是进度条。说「固定时刻更容易想起来」，不说「必须」。
4. **不追问练习中出现了什么内容**（尤其想法内容）。
5. 出现明显不适 → 停止 + 转卡 8，不加码。

**这张卡最容易犯的错**：把它做成「情绪急救按钮」——
用户按一下，期待情绪下降；没下降就认为方法无效或自己不行。

**正确的收尾**：不问「好点了吗」，只问「刚才有没有注意到自己在什么状态」。
