## I · 核心洞见

**「我到底做对了没」——这个问题本身就是答案：你在行动模式里。**

这不是文字游戏。行动模式的定义特征就是**检查差距**：
现状 vs 应有、现在 vs 目标。
一旦你开始检验「我有没有专注」「我做得对不对」，
你就把练习变成了又一件要完成的任务。

### 最实用的判据（p05）

> **你在这个过程里，有没有反复回头检查「好点了吗」？**
> 有 → 你在驱赶，不是在觉察。

这个判据很狠，因为检查动作极其隐蔽——它感觉像「负责」「认真」。
但同一个动作，可以是照顾，也可以是驱赶，**区别就在那个回头的动作**。

### 七组对照（f01，简化版）

| | 行动模式 | 存在模式 |
|---|---|---|
| 关注 | 缩小差距 | 允许如其所是 |
| 时间 | 过去与未来 | 当下 |
| 加工 | 通过思维加工经验 | 直接感知经验 |
| 对痛苦 | 回避、去除 | 有意愿地接近 |
| 对想法 | 看作真实 | 看作心理事件 |
| 姿态 | 需要事物有所不同 | 允许事物如其所是 |

**用法**：不要求记住七条，只用来**事后对照**——「刚才那一段，我更像在哪一栏？」

## A1 · 书中案例

**案例一：把练习做成考核（x07）**
一位学员每次练习后都评估「这次专注了多久」。越评估越焦虑，最后不敢练。
**方法要点**：评估的对象错了——从「我有没有专注」换成「**我有没有注意到**」。
走神一次并注意到，就是一次成功的练习；全程专注但没注意到走神，反而什么都没练到。

**案例二：越练越急（x11）**
另一位学员急着「练出效果」，把每天练习当成进度。
**方法要点**：急本身就是行动模式。用行动模式去练「退出行动模式」，结构上不成立。

## A2 · 触发条件

**用户会在这些情境下需要它：**

1. 问「我这样算做对了吗」
2. 每次练完都评估效果
3. 说「我好像一直在分析，不是在觉察」
4. 越练越急、越练越焦虑
5. 因为「做不好」而不敢继续练

**语言信号**（中／英）：
- 「我做对了吗」「这样算不算」「是不是方法不对」
- 「我一直在分析」「越练越急」
- "am I doing this right" / "I think I'm overthinking it" / "I'm not sure it's working"

**与相邻卡的分工**：
- 与**卡 7**：卡 7 处理「做多少」，卡 9 处理「怎么判断做对了」。
- 与**卡 8**：卡 9 处理自我评价，卡 8 处理反应强度。**分流见卡 8 第零步。**

## E · 执行步骤

**第一步：不问「做对了吗」，问「刚才发生了什么」**（1 分钟）

> 「先不评价。刚才那几分钟，你实际做了什么？」

要具体的：坐下了、注意到呼吸了、走神了几次、注意到走神了吗。

**为什么这样问**：评价会立刻把人拉进行动模式；
描述事实不会。这一步本身就是在示范存在模式。

**第二步：换评估对象**（1 分钟）

> 「不问你专不专注。问：**刚才有没有一次，你注意到自己走神了？**」

- 有 → 那就是练习发生了
- 没有 → 那也只是「这次没注意到」，不是失败

**完成标准**：用户能说出一次「注意到」的具体时刻。

**第三步：做一次意图检验**（2 分钟）

> 「你练的时候，有没有在等一个感觉？」

若有 → 说出来：「那是在等效果。等效果会让你更紧。」
**不加评判**，因为等效果是所有人的默认反应。

**第四步：给一句「不检查」的许可**（1 分钟）

> 「接下来几次，不看效果，只看到场。做了就算。」

**判停点**：
- 若用户说「不看效果那我练它干嘛」→ 这是真问题，不要绕。
  回应：「现在没法给你一个保证。能说的是：检查效果本身会让你更紧。」
- 若用户的自我批评已经很重 → 先处理那个（可能需转自我关怀分册）

**补充案例（c01）**
初次做身体扫描，注意力不断跑开，跑开之后立刻评判「我是不是做错了」——而评判本身又变成新的干扰。
**方法要点**：把目标从「让注意力不跑」换成「跑开后注意到它跑开了」。
注意 vs 控制，是这张卡的分水岭。

## B · 边界

**不要用这张卡的情形：**

1. **用户在报告身体/情绪反应变强** → 转卡 8（分流见卡 8 第零步）
2. **用户问的是具体做法对不对**（「手该放哪」）→ 直接答技术问题，不上本卡
3. **用户的核心议题是「我对自己太狠」** → 转自我关怀分册。
   本卡的「别检查效果」在这个人群身上会变成「连检查都不许」
4. **有自伤/自杀意念** → 危机硬停

**书中警告过的失败模式：**

| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| **x07 练习变成考核** | 「我这次专注了多久」 | 把练习变成又一件做不好的事 |
| **x11 越练越急** | 边练边验收效果 | 用行动模式退出行动模式，结构不成立 |
| 追求「正确的体验」 | 「我应该有那种感觉」 | 书里明说经验没有「正确」的版本 |
| **x12 做成放松/放空** | 「我要什么都不想」 | 放空是关闭，不是觉察；两者的区别正是本卡要分的 |

**护栏硬约束（本卡专属）：**

1. 🔴 **不问「好点了吗」「有没有进步」** —— 这个问题本身就是行动模式。
2. 🔴 **不说「你方法错了」**。方法可以调整，但不给「错」这个判定。
3. **不承诺「不检查就会有效」** —— 那又是新的效果承诺。
4. **不给「标准体验」的描述**（如「你应该感到平静」）——
   书里明确：经验没有正确版本。
5. 自我批评很重 → 转自我关怀分册，不在本卡加码。

**这张卡最容易犯的错**：给用户一个「正确练习」的标准，然后帮他对照。
那会把本卡的用意整个反过来。

**正确的收尾**：不用做对。只需要注意到。
