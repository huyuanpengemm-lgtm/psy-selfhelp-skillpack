## I · 核心洞见

> **依据等级 B**——本段是对方法的理解与综合，**不是研究结论**。

"不发火就没人听"这句，书里直接反过来说：你越大声，对方越在保护自己，越听不见你。

让人听进去的不是音量，是一句话的结构：**我观察到什么 → 我感到什么 → 我希望你做什么。**

三段各有雷区：第一段不许下判断；第二段不许说「你让我」；第三段只求行为、一次只求一件。
**请求能被执行的，才会被听见。**

### 先分清三种应对

| 类型 | 做法 | 真实代价 |
|---|---|---|
| **消极** | 不说，表面随和 | 没人看得见真实的你；积怨；最后从别处炸 |
| **攻击** | 说赢，逼对方就范 | 对方要么反击要么疏远；**你永远不知道他是出于爱还是怕** |
| **坚定而自信** | 说清要什么，不评人 | 要练，但代价最小 |

**关键一句**：慢性消极不是第三种选择，是**延期的攻击**——书里说，这种人"内心都充满了愤怒"。

### 三段：书里给的反例与正例

| 段 | 书里的反例 | 书里的正例 |
|---|---|---|
| **事实** | "你这么懒呀，直到现在才洗刷碗盘？" | "我看到洗涤槽中堆满了昨晚吃过的脏碗盘。" |
| **感受** | （书里只说要抛弃指责和内疚式表达，未给例句） | "当我下班回到家时，发现厨房洗涤槽里的碗盘时，我感到很生气。" |
| **请求** | "我希望你成为百万富翁"（具体，但不可操作） | "我希望你在看电视前把碗洗了。" |

**请求三条硬约束**：可操作 · 一次一件 · **只求行为，不求态度**（求「愿意去」永远无法验收）。

### 后果（可选）

具体 · 合理 · 前后一致 · **自己受得了**。第四条最常被跳过：书里有人以「不参加毕业典礼」为后果，
为了守信真的没去，多年后仍在后悔——**设后果前先问：对方真选了那一边，我受得住吗。**

🔴 禁令：不用暴力威胁、不当众羞辱；不用"离婚 / 自杀 / 再也不"这类最后通牒。

### 谈判六步（参考，不必全走）

说清要什么 → 说要对方改哪个行为 → 听对方（**收集信息，不等于同意**）→ 提一个把对方需要也算进去的方案 →
请对方提反对方案 → 定一个可撤回的小安排。

## A1 · 书中案例

**两件事，两种处理。**
**方法要点**：一是柜台前被少找了钱——插队大声索要（得手但结怨）、沉默走开（损失且积怨）、
等对方忙完再陈述事实并提要求（得手且不结怨）；二是把一团"我受够了"拆成
"明确目标 → 多个备选 → 逐条列后果 → 选一个并定下第一步"。**都不靠音量。**

## E · 执行步骤

**先写，不先说**：

1. **事实**：只写看见听见的。删掉"总是 / 从来 / 根本 / 故意"。
2. **感受**：用"我…"，不用"你让我…"。
3. **请求**：一个动作 + 什么时候 + 做什么。**只一件。**
4. **（可选）后果**：写完问"他真选了那一边，我行吗"。

**判停**：自己听着像指责 → 回第 1 步。想说三件 → 只留最想解决的那件。
想加「你以后要尊重我」→ 删掉，那句无法执行。

## B · 边界

**不要用这张卡的情形**：🔴 对方在恐吓你、有暴力，或你正在用发火控制对方 → 不给脚本，转**卡 8**。
在权力不对等的关系里，这套话术会被用来**更省力地维持关系**，不是改变它。

**失败模式：**

| 失败模式 | 表现 | 为什么错 |
|---|---|---|
| **x05 "不发火没人听"** | 提高音量、加脏字 | 对方进入防御，听见的更少 |
| **一次提三件** | 把攒了半年的账一次说完 | 对方只听见"你又在挑刺" |
| **x07 最后通牒** | "再这样我们就完了" | 说了就得执行；不执行就贬值 |

**护栏硬约束：**
1. 🔴 **脚本里不得出现暴力威胁、当众羞辱、离婚 / 自杀式最后通牒**。
2. 🔴 **只求行为改变**，不要求对方改感受或价值观。
3. 🔴 **后果必须"自己受得了"**——这一条要当场问出来。
4. 谈判六步只作参考，**不要求全走**，也不给"应该谈到什么结果"。
