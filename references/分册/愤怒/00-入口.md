# 愤怒

> **本分册是心理自助性质的工具，不构成诊断、治疗或用药建议。**
> 如有自伤或伤人念头请拨 **12356**（24 小时）。

## 入口三道前置（顺序不可颠倒）

### 0 · 危机筛查

有自伤、伤人、被伤害的现实风险 → **先安全，不走本册**。

### 1 · 先问"谁在发火"

| 情形 | 走哪 |
|---|---|
| **我发火，我怕伤到人** | 本册（先过第 2 道） |
| **对方发火，我在挨** | ❌ **不走本册**。本册不教"如何安抚一个会发火的人" |
| 双方都在发 | 先看谁的那条线越过了 |

**这一道不问清，后面全是废动作**：给一个正在挨吼的人讲"三 F"，等于让他用更体面的方式继续挨。

### 2 · 暴力与控制分流 → 卡 8

**命中任一条，不给任何技巧**：动过手（推、拽、砸、挡门）／用发火让对方屈服且觉得管用／
对方已不敢说不同意见／以自伤、离婚、带走孩子作威胁。

**为什么不能给**：在权力不对等的关系里，这套话术会被用来**更省力地维持关系**，而不是改变它。
而且"我试过好好说，没用"之后，人会把这笔账记到自己头上——**"是我没说好"**。

## 七张卡 + 一张闸门

| # | 卡 | 用户会说 |
|---|---|---|
| 1 | **愤怒是信号，不是罪** | 「我就是脾气爆」「我知道不该生气，一直忍着」 |
| 2 | **一份痛苦，一根火柴** | 「一点就着」「不知道为什么就火了」 |
| 3 | **六种把火吹大的想法** | 「我知道不该这么想，但做不到」 |
| 4 | **当场那一分钟**（附：在哪儿练） | 「当时根本控制不住」「我上哪儿练」 |
| 5 | **火底下是什么** | 「发完火好受一点」「我火很大，说不清为什么」 |
| 6 | **不用提高音量也能被听见** | 「不发火没人听我的」 |
| 7 | **说"不"，和挨批评** | 「一拒绝就吵」「一被说我就炸」 |
| 8 | 🔴 **什么时候这套不能用** | 「我上次推了她」「我一吼他就听话」 |

**阅读顺序**：卡 8 是闸门（先过）；卡 1 定立场；卡 2 看机制；卡 4 管现场；
卡 3、5、6、7 是四条不同的下刀处，可单用。
**卡 4 必须早于卡 5**：先会停，再问底下是什么。反过来会出现"一边发火一边挖童年"。

## 🔴 这一册最硬的四条

### 一、不教「发泄降火」

**这是本册最容易做错的地方，也是书里立场最硬的一处。**

流行说法是"攒着会生病，要释放出来"。**这本书明确反对，三条独立证据：**

| 证据 | 原文 |
|---|---|
| 效果是假的 | "尽管你发泄愤怒的时候好像释放了不快的情绪，但它还是会使我们内心的痛苦加剧。" |
| 生理假设是假的 | "长期发泄愤怒是同高血压和精神过度紧张有关的。所以，压抑愤怒与发泄愤怒之间的区别并不重要。" |
| 机制是反的 | "虽然这种放松感很短暂"＋"但释放愤怒还是极大地得到了强化" |

**所以：本册任何卡片，不得出现"释放 / 宣泄 / 倒出来 / 喊出来 / 打枕头"这类动作或比喻。**
**"宣泄"一词全书 0 次；"发泄"9 次，其中 8 次是被批评的对象——它是病名，不是方法名。**

### 二、但也不主张压着

这一条与上一条必须同时给，否则用户只收到一半，然后开始自责式地忍。

> "如果你试图强行压抑自己的愤怒，你也许会真切地感受到由此引发的痛苦。"
> "不要让这种体验肆意发泄，但是也不要试着去压抑它。"

**第三条路**：让感受完整经过（看它涨落），**但不做动作**；然后把需要改成一句能被听懂的请求。

**说死**：**不许把"我忍住了"写成成功。** 忍住只是把账延后。

### 三、不把愤怒当坏事

> "愤怒本身并没有过错，它仅仅是你处在痛苦之中的一个信号。唯一的问题是当你依着愤怒去做事时，你就会伤害到他人或自己。"

**所以本册不评价"你该不该生气"**，也不以"降低愤怒"为唯一目标。
**同时**：真的有人在侵害你时，愤怒是恰当的——这一条也来自原文，不能只给前半句：

> "当有人确实想排挤或威胁你时，愤怒可能是一个恰当和健康的反应。它是一个使他人屈服的信号。"
>
> 紧接的一句同样是原文，也必须一起给："然而，在大多数情况下，愤怒是一种过火的行为，我们并不需要它。"

### 四、不做「愤怒类型」自评

**不给**：愤怒类型问卷、A 型/B 型分类、分数分档、"你是几级愤怒"。
**书里有一整套分数刻度（用于安排练习难度）+ 一套人格类型标签（1950–70 年代），两者都不进卡。**

**理由**：类型会变成一个**身份**（"我就是暴躁型"），而身份比行为难改；分档会变成一次自我判决。

## 五条判据（本册最有用的部分）

**1 · 这股劲落到人身上了吗**
不是"我该不该生气"，是"我做了什么、说了什么"。
> 愤怒是信号，动作才是问题。**评价对象永远是动作。**

**2 · 这一句里，哪一层是编的**
伤害 / **故意** / 错误。三层里中间那层几乎总要出错——因为它是对别人脑子里的东西下的结论。
> 问法只有一个："你看见、听见的是什么？"

**3 · 发出来之后，我拿到了什么**
不是"值不值"，是"换到了什么"。**发火是有回报的**——不承认这一点，任何劝阻都推不动。
> 承认收益 → 再算账 → 再问"同样这个东西，有没有不用火的拿法"。

**4 · 这是"事"变了，还是"底子"变了**
同一句话昨天能忍今天炸，变的通常不是那句话。
> 出事前我已经有什么不舒服？**这一格最能改，也最常被跳过。**

**5 · 现在能不能平静说话**
冷却的判据不是时长，是状态——"直到你能够再次平静行事"。
> 用"我能不能把对方那句话原样复述一遍"来判，比看表准。

## 与相邻分册的边界

| 相邻 | 分工 |
|---|---|
| **关系亲密** | 那册处理两人之间的冲突模式与依恋；本册只处理"我这一头的火"。同一场吵架不重复给动作 |
| **焦虑·惊恐** | 那里是恐惧驱动、目标是**接近**；这里是"被冒犯"驱动、目标是**不伤人**。🔴 **暴露方向相反**：焦虑册在唤醒里学，本册降唤醒。不可互推 |
| **DBT / 情绪调节** | 那册讲整体调节与痛苦耐受；本册只管"从有火到做动作"这一段 |
| **自我关怀** | 那册讲对自己的态度；本册只碰"发完火之后别把自己判死刑"这一小块 |
| **抑郁** | 易怒可能是抑郁的一部分。若同时有持续低落、兴趣减退 → **先按抑郁册走** |
| **失眠** | 愤怒与睡眠互相拖累；先处理哪头看哪头更影响白天 |

### 跨册同名不同义（必须写清）

| 词 | 本册 | 冲突 |
|---|---|---|
| **离开 / 回避** | 本册的"离开情境"是**降唤醒的推荐动作** | 焦虑册里"回避"是维持症状的错误动作；ACT 里是妨碍价值。**同名，判定相反** |

### 引号约定（读本册时请先看这一条）

| 记号 | 含义 |
|---|---|
| **" "** ＋ 前有"书里"或后跟行号 | **原文逐字**。72 条全部程序化回原文核过，一个字未改 |
| **" "** 其他位置 | **标出关键词或口头语**（如"忍住""他故意""发出来"），不是引文 |
| **「 」** | **我们或用户会说的话**（示范句、问句、用户原话） |
| 无记号 | 我们的概括与说明 |

**这条约定存在的原因**：本册最容易犯的错，是把"我们的转述"放进引号，
读者拿着引号里的话回原文找不到。**凡当作原文引用的，都能在原文里逐字找到。**

## 一处必须说明的偏差

**这本书是写给"发火的人"的，不是写给"被吼的人"的。**

所以本册在入口做了"谁在发火"的分流——这不是书里的结构，是**必要的改造**。
如果不做，本册会被误用于"如何让一个会发火的人对我好一点"，而那正好是最危险的用法。
