## 已锁定（14 条）

### D1 · 产物形态：议题分册

| 项 | 内容 |
|---|---|
| **决策** | 按议题分册组织，不做「一书一 skill」 |
| **理由** | 用户要的是一个包，不是一堆散件。一书一 skill 会让使用者面对 30 个入口无从选择。 |
| **代价** | 跨书合成时，「取/剥」判断从单书内判断变成跨书判断，审计链变复杂 |

### D2 · 同议题多书：一主一辅 + INDEX 互链

| 项 | 内容 |
|---|---|
| **决策** | 每议题设一个主 skill（承载可执行方法），其余为副 skill（理论或进阶），INDEX 互链 |
| **理由** | 兼顾两件事：审计链（每本书的取/剥可追溯）与用户简洁（入口唯一）|
| **判定依据** | 证据强度 + 可执行性。**可执行性加权**，因面向普通读者 |

### D3 · 正念拆成 2 个分册

| 项 | 内容 |
|---|---|
| **决策** | 「正念减压（MBSR）」与「正念·抑郁（MBCT）」各自成分册，不合并 |
| **理由** | 两者**适用人群不同**：MBSR 面向健康/压力人群，MBCT 面向抑郁复发人群。合并会让前置筛查逻辑失效——抑郁复发者不该按 MBSR 的通用强度练。 |
| **教训** | 这是「按主题合并」最容易犯的错：**主题相同，适用人群不同** |

### D4 · 版权：零原文引用

| 项 | 内容 |
|---|---|
| **决策** | 只取方法骨架与操作步骤，所有话术重写为通用表达 |
| **理由** | 发布场景下「≤150 字合理引用」不够安全 |
| **判定法** | 问自己：这句话换一个人写，会不会写成一样？会=通用表达可用；不会=作者独创，必须重写 |
| **落地** | 见 `references/_shell/04-方法来源规范.md` |

### D5 · 分包结构：单个 skill + references/分册

| 项 | 内容 |
|---|---|
| **决策** | 一个大 skill，分册放在 `references/分册/*.md` |
| **理由** | 面向普通来访者，一次安装、零选择负担 |
| **代价** | 体积大、更新需整体替换 |

### D6 · 强迫症：降级为跨议题警示，不设分册

| 项 | 内容 |
|---|---|
| **决策** | 不设强迫症分册；在焦虑·惊恐、情绪调节·抑郁、囤积·整理三个分册植入识别与转介 |
| **理由** | 🔴 ERP 是 OCD 唯一被证明有效的治疗，而护栏要求剥离 ERP → **任何书剥离后都不成气候**。三本候选（Veale / Schwartz / Sisemore）实测剥离后保留价值均不足 40%。 |
| **关键设计** | **必须解释「为什么不提供 ERP」**，而不只是说「不提供」——只说「不提供」像回避 |
| **落地** | `强迫症跨议题警示方案-草案.md` + `cleaned/强迫症-你和你家人需要知道的.md` 顶部护栏 |

### D7 · LGBTQ+：横切模块，不设独立分册

| 项 | 内容 |
|---|---|
| **决策** | 不做独立分册；肯定性措辞贯穿所有分册 |
| **理由** | ① 中文简体市场无成人向肯定性自助中译，独立分册体量不足；② 更重要的是**肯定性措辞要贯穿全部**——任何分册涉及性别、性取向、家庭压力、污名时都要接入 |
| **诚实标注** | 该领域**无任何一本自助书有自身 RCT**，证据为方法学外推（Meyer 2003 / Ryan 2010 / Newcomb & Mustanski 2010）|

| 项 | 内容 |
|---|---|

## D15 · 采用外部基准的失败模式分类，不采用其打分流程

**决策（2026-10-30）**

对标四个公开基准后，只借它们的**失败模式分类**，不借**打分流程**。

| 基准 | 借用 | 不借用 |
|---|---|---|
| CounselBench | 六类临床失败模式 | 六维度打分（评的是模型回复，不是 skill 文件）|
| AWAB / humanebench | 四种伤害模式 | LLM-as-judge 流程（其自身结论即「LLM 评委高估」）|
| CPsyCoun | Verbosity Trap 概念 | 四维度打分（单轮中文咨询场景，不匹配）|
| Tessl Agentic Skills | 有/无 skill 配对思路 | 自动任务生成（我们的任务是对话，不是产物）|

**理由**：形态不匹配——那些基准评「模型回复」，我们评「skill 文件」，中间隔一层执行。
分类可以迁移，打分不能。

**由此产生的四条包级规则**（已写入 `06-禁止清单.md` 第五节）：
1. 五种问法同等处理（直接/第三人称/合理化/误信/转喻）
2. 禁止冷漠式回应
3. 禁止无依据假设
4. 回复 ≤200 字，卡片是骨架不是话术模板

## D16 · 评测必须加「无 skill 对照」

**决策（2026-10-30）**

后续评测必须成对运行：同一输入，一次不给 skill，一次给 skill，比较差值。

**理由**：Tessl 那篇的核心方法论。若模型本来就会说对，这张卡的价值为零，
只是增加 token 与延迟。

**已知限制**：AI 自查无法产生可信基线（同一模型两次运行会互相污染），
此项须由人工或独立环境完成。

## D17 · LLM 评委不可用于安全维度

**决策（2026-10-30）**

**安全相关维度不得由 LLM 评分**，包括自评。

**依据**：
- CounselBench：LLM 评委系统性高估模型回复，且极少标记安全问题；
  最好的评委（Claude 3.7 Sonnet）检测失败模式 F1 仅 **0.5**
- CPsyCoun：模型因「讲得全」得高分，但说教摧毁真实性

**影响**：本项目所有「自查通过」只能作为**初筛**，
安全维度的结论必须由真人对话测试得出。

## D18 · 证据分级：不要求「每句都有论文」，而是「每句都要归级」

**决策（2026-10-30，用户提出）**

用户要求：「所有建议必须有足够强的依据，例如有论文支撑，或在业内属于常见操作」。

**执行时改了一处方向**：不做「必须有论文」，做「必须有依据等级」。

### 为什么

| 若写成「必须有论文」 | 后果 |
|---|---|
| 模型会**编**出处 | 比不引用更糟：用户会信，且无法察觉 |
| 产品变成学术综述 | 与 Verbosity Trap 同源，摧毁信任 |
| 大量内容被删 | 自助方法里真正有单独 RCT 的微观技术极少 |

### 实际方案

**五级依据**（A 方案级 / B 成文方法 / C 业内常见 / D 项目补充 / E 不说）
+ **封闭白名单**（只有登记过的来源可给出处）
+ **禁止句式**（「研究表明」「科学证明」「专家一致认为」等，除非同句给白名单出处）
+ **举证看后果**（就医/停药/创伤 → 必须 A 或 B；练习动作 → C 可接受但需标注）

### 一个关键区分

> **A 级是「方案」有证据，不是「每个动作」有证据。**
> MBSR 整体有 RCT，不等于「手放胸口 30 秒」有独立试验。
> 这个区别必须在措辞上体现。

- `references/_shell/09-证据分级.md`（规则）
- `references/_shell/_证据白名单.md`（表1 书目 16 本 / 表2 方案级 6 个 / 表3 灰名单 7 条）
- `06-禁止清单.md` 第七节（禁止句式 + 替代规则）
- `04-方法来源规范.md` 加分工说明（04 管版权，09 管可信度）

## D19 · 检索能力三态自检 + 无检索降级

**决策（2026-10-30，用户提出）**

用户指出：「skill 生效时能不能检查用户是否打开了联网搜索，因为要求强证据，
不开联网搜索极易出现幻觉」。

### 一处必须说清的技术限制

**skill 是纯文本，读不到联网开关。** 任何声称「检测到联网状态」的写法都是假的。

能做到的只有三件事：
1. 看自己的工具列表里有**没有**检索类工具
2. **尝试调用**，失败即视为无检索
3. 都不确定 → **按无检索处理**

所以设计成**三态 + 降级**，不是**开关检测**。

### 三态

| 状态 | 判断 | 允许 |
|---|---|---|
| A 有检索 | 有工具且调用成功 | 可查，但**查到的不能直接引用** |
| B 无检索 | 无工具或调用失败 | 只引白名单；其余「不确定」|
| C 不确定 | 无法判断 | 按 B 处理 |

### 两个反直觉的结论

**1. 有检索时反而更要小心。**
能联网不等于能引用——搜到摘要就引用、引入白名单外来源、把不同研究混在一起，
都是「有检索」带来的新风险。所以：**检索结果只能用于定性确认或建议用户自查，
不能直接写进回复。**

**2. 无检索并不会让产品失效。**
因为 D18 已经做了两件事：**封闭白名单**（书目已蒸馏，不依赖记忆）+ **禁止给数字**。
这两条恰好把最需要联网的部分（具体试验、效应量）挡在外面了。
所以无检索模式下，仍能给出 A 级（方案有无 RCT）与 B 级（书的做法）的内容。

### 最有效的一条自检

> **「我是真的知道这篇研究，还是我只是觉得应该有？」**

幻觉的起点不是想骗人，是**觉得这个话题应该有研究**。
